# 質問と回答

これまでに受けた技術的な質問の一覧です。回答の本文は、内容に合うページに追記しています。

- CodeCommit や GitHub があれば CodeArtifact は不要か: [Git リポジトリがあっても必要か](../services/cicd.md#codeartifact-need)
- CodeConnections とは何か: [CodeConnections の接続](../services/cicd.md#codeconnections)
- 各リソースの提供単位（グローバル、リージョン、AZ、VPC）と、EC サイトの構成図の例: [リソースの提供単位と EC サイトの構成例](../services/resource-scope.md)
- SAML の具体例（アサーションの中身、信頼ポリシー、CLI、Identity Center との違い）: [SAML 2.0 の具体例](../services/iam.md#saml)
- 略語（STS、RCP、SCP など）の正式名称: 各ページで最初に出たところに（）で自動表示。対応表はリポジトリの `data/abbreviations.json`
- 権限境界と SCP の設計意図、オンプレミスとの対比: [なぜ必要か](../services/iam.md#boundaries-scp-why)。各サービスのページにも「なぜ」の節と対比の表を追加
- どういうときに使うか、業種ごとの具体例: 各サービスのページの「使いどころと具体例」。例: [Lambda](../services/lambda.md#use-cases)、[S3](../services/s3.md#use-cases)、[SQS / SNS / EventBridge](../services/messaging.md#use-cases)
