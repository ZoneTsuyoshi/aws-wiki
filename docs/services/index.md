# サービス解説

AWS サービスの解説です。試験に関係なく参照でき、[試験別コース](../courses/index.md)からもリンクしています。

## 試験バッジの見方 {#badges}

ページや見出しのバッジは、そのサービスがどの試験で必要かを示します。選ぶと、その試験のサービス一覧に移動します。

| 表示 | 意味 |
|---|---|
| 塗りつぶし | 試験ガイドの公式の対象サービスに載っている |
| 枠線のみ | 公式の一覧にはないが、そのコースの解説で3回以上参照している |
| 色 | 緑: 基礎、青: アソシエイト、紫: プロフェッショナル、橙: 専門知識 |

試験ごとの一覧は[試験別コース](../courses/index.md)の各コースにあります。
