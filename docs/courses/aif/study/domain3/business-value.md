# 分野3: 事業目標との整合

スコアが高くても、事業の目的を満たすとは限りません。目的に合う指標を選びます。

## 問われるスキル {#skills}

| スキル | 内容 |
|---|---|
| [3.4.3](../../domain3.md#obj-3-4-3) | FM が事業目標を満たすかの判断 |
| [3.4.5](../../domain3.md#obj-3-4-5) | 事業目標との整合を測る指標 |

## 学習の順番 {#study-order}

1. [ビジネス指標](../../../../services/ai-fundamentals.md#business-metrics): 指標の区分を確認します。
2. [利用者からの評価](../../../../services/genai-apps.md#user-feedback): 利用者の評価の集め方を押さえます。
3. [KPI と ROI](../../../../services/ai-fundamentals.md#kpi-roi): 有形と無形、先行と遅行の指標の違いを確認します。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 作業時間が減ったか | 生産性 |
| 使い続けられているか | 利用者の関与 |
| 出力を修正せず次へ渡せるか | タスクの設計 |
| 人に回さず解決した割合 | タスク完了率 |
| 評価ボタンの集計 | 利用者の満足度 |
| 1 回の対応の費用 | やり取りあたりのコスト |

## 引っかかりやすい点 {#traps}

- 「task engineering」はガイドに定義がありません。この wiki の解釈です。
- 精度が高くても、1 回の費用が人より高ければ事業は成り立ちません。
