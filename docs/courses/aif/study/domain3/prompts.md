## 学習の順番 {#study-order}

1. [プロンプトエンジニアリング](../../../../services/ai-fundamentals.md#prompt-engineering): 構成要素、手法、リスクの 3 つの表を順に覚えます。
2. [多層防御](../../../../services/genai-apps.md#defense-in-depth): プロンプトだけに頼らない防御を確認します。
3. [プロンプトの管理](../../../../services/genai-apps.md#prompt-management): バリアントとバージョンの違いを押さえます。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 例を示さない | ゼロショット |
| 例を 1 つ示す | シングルショット |
| 例を複数示して基準を伝える | フューショット |
| 段階的に考えさせる | Chain-of-thought |
| 変数つきの定型文 | プロンプトテンプレート |
| システムプロンプトを聞き出す | 露出 |
| 文書や学習データに悪意ある内容を混ぜる | ポイズニング |
| 別の目的に使わせる | ハイジャック |
| 架空の設定で安全策を回避する | ジェイルブレイク |
| 別案を比較する | バリアント |
| 本番を固定し、前に戻せるようにする | バージョン |

## 引っかかりやすい点 {#traps}

- 「あなたは法務担当です」は文脈で、「JSON で返す」は出力形式です。
- プロンプトに機密を入れると、露出のリスクが増えます。
- 「using multiple comments」はガイドに定義がありません。この wiki では、指示を分けて書くことと解釈しています。
