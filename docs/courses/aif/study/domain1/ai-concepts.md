## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 「正解のラベルがある」 | 教師あり学習 |
| 「ラベルがない」「グループを見つける」 | 教師なし学習 |
| 「試行錯誤」「報酬」 | 強化学習 |
| 人が書いた規則だけで動く | ルールベース。ML ではない |
| ツールを実行して手順を自分で決める | エージェント型 AI |
| 学習データでは高精度、検証データでは低精度 | 過学習 |
| 文書、画像、音声 | 非構造化データ |
| 順序に意味のあるデータの分割 | 時間順に分ける |

## 引っかかりやすい点 {#traps}

- 推論は学習ではありません。学習済みのモデルで予測する処理です。
- 時系列をランダムに分けると、未来のデータが学習に混ざります。
- 深層学習は機械学習の一部です。AI のすべてが機械学習でもありません。
- 問題文の「バイアス」は、統計の意味か公平性の意味かを文脈で見分けます。
