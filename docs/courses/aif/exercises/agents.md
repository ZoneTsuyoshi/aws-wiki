# エージェントの問題集

対象の解説: [エージェント](../../../services/ai-fundamentals.md#agents)、[エージェントのパターンと MCP](../../../services/genai-apps.md#agent-patterns)、[AgentCore のアーキテクチャ](../../../services/genai-apps.md#agentcore)

### 問1 {#q1}

エージェントの基本的な動きとして正しいものはどれですか。

- A. 文書をチャンクに分けて埋め込みを作り、ベクトルストアに保存する
- B. 決められた規則に従って、常に同じ回答を返す
- C. 学習データを受け取り、重みを更新して終わる
- D. 次の手順を考え、ツールを実行し、結果を確認することを繰り返す

??? success "答えと解説"
    **正解: D**

    目標に向けて考える、実行する、確認するを繰り返すのがエージェントです。

    - A: 誤り。それは RAG の事前準備の説明です。
    - B: 誤り。それはルールベースの説明です。
    - C: 誤り。それはモデルの学習の説明です。
    - D: 正しい。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [エージェント](../../../services/ai-fundamentals.md#agents)

### 問2 {#q2}

複数のエージェントから、同じ社内データベース用のツールを標準の方法で使いたいと考えています。適切な仕組みはどれですか。

- A. MCP（Model Context Protocol）
- B. A2A
- C. Agents as Tools
- D. プロンプトチェーン

??? success "答えと解説"
    **正解: A**

    MCP はエージェントとツールやデータをつなぐ標準プロトコルで、ツールを複数のアプリで再利用できます。

    - A: 正しい。
    - B: 誤り。エージェント同士の通信の仕組みで、ツールとの接続の中心ではありません。
    - C: 誤り。エージェントを別のエージェントのツールとして呼ぶ構成で、社内データベースを標準の方法でつなぐ仕組みではありません。
    - D: 誤り。前の出力を次の入力に渡す流れで、ツールとの接続の標準ではありません。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [MCP](../../../services/genai-apps.md#mcp)

### 問3 {#q3}

別々の基盤で作られた 2 つのエージェントに、標準のプロトコルで通信させたいと考えています。適切なものはどれですか。

- A. MCP
- B. A2A（Agent-to-Agent）
- C. Agents as Tools
- D. AgentCore Memory

??? success "答えと解説"
    **正解: B**

    A2A はエージェント同士の通信です。MCP と区別して覚えます。

    - A: 誤り。エージェントとツールやデータをつなぐ仕組みです。
    - B: 正しい。
    - C: 誤り。同じ基盤で上位が下位を呼ぶ構成で、基盤をまたぐ通信のプロトコルではありません。
    - D: 誤り。記憶を提供するサービスで、エージェント間の通信のプロトコルではありません。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [マルチエージェント](../../../services/genai-apps.md#multi-agent)

### 問4 {#q4}

上位のエージェントが、調査担当や計算担当のエージェントをツールとして呼び出す構成はどれですか。

- A. Graph
- B. A2A
- C. Agents as Tools
- D. Swarm

??? success "答えと解説"
    **正解: C**

    上位が下位を指示するのが Agents as Tools です。

    - A: 誤り。開発者が定義した流れ図に沿って、経路を選びながら進める構成です。
    - B: 誤り。別々の基盤のエージェントがプロトコルで通信する仕組みです。
    - C: 正しい。
    - D: 誤り。エージェント同士が対等に仕事を引き継ぐ構成です。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [マルチエージェント](../../../services/genai-apps.md#multi-agent)

### 問5 {#q5}

複数のエージェントが、中央の指揮役なしで互いに仕事を引き継いでいく構成はどれですか。

- A. Agents as Tools
- B. Graph
- C. Swarm
- D. プロンプトチェーン

??? success "答えと解説"
    **正解: C**

    エージェント同士が対等に引き継ぐ構成が Swarm です。

    - A: 誤り。上位のエージェントが下位に指示する構成です。
    - B: 誤り。開発者が定義した流れ図に沿って進める構成で、引き継ぎ先を自由に決めるものではありません。
    - C: 正しい。
    - D: 誤り。前の出力を次の入力に渡す単純な流れです。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [マルチエージェント](../../../services/genai-apps.md#multi-agent)

### 問6 {#q6}

エージェントの記憶の説明として正しいものを選んでください。（2つ選択）

- A. 長期の記憶には、会話からの知識は保存できない
- B. 短期の記憶は、今の会話のやり取りを保持する
- C. 短期の記憶は、モデルの事前学習の重みを保持する
- D. 長期の記憶は、利用者の好みや過去の事実を保持する
- E. AgentCore Memory は、記憶を持たないステートレスな実行だけを提供する

??? success "答えと解説"
    **正解: B, D**

    AgentCore Memory は、短期（イベント）と長期（抽出した知識）の記憶を提供します。

    - A: 誤り。短期の記憶から抽出した知識を保存します。
    - B: 正しい。
    - C: 誤り。重みはモデルの一部で、エージェントの記憶ではありません。
    - D: 正しい。
    - E: 誤り。短期と長期の記憶を提供するサービスです。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [Memory の設計](../../../services/genai-apps.md#agentcore-memory)

### 問7 {#q7}

「問い合わせを受けて請求か技術かに分類し、専門の処理に送る」というワークフローのパターンはどれですか。

- A. 並列化
- B. ルーティング
- C. ファインチューニング
- D. 評価と改善

??? success "答えと解説"
    **正解: B**

    分類して専門の処理へ送るのはルーティングです。

    - A: 誤り。同時に実行して統合するパターンです。
    - B: 正しい。
    - C: 誤り。モデルの重みを調整する手法で、パターンではありません。
    - D: 誤り。別のモデルが採点して直すパターンです。

    **スキル:** [2.1.6](../domain2.md#obj-2-1-6) / **参照:** [構造のパターン](../../../services/genai-apps.md#workflow-patterns)

### 問8 {#q8}

通常のチャットとエージェントの違いとして正しいものはどれですか。

- A. エージェントはツールで外部のシステムを変更できる
- B. チャットは複数の手順を実行するが、エージェントは 1 回答えるだけである
- C. エージェントは常に人の次の指示を待ってから動く
- D. チャットだけが FM を使い、エージェントは FM を使わない

??? success "答えと解説"
    **正解: A**

    エージェントは目標に向けて複数の手順を実行し、ツールで外部を変更できます。

    - A: 正しい。
    - B: 誤り。逆です。
    - C: 誤り。自分で次の手順を決めます。人が次の指示を出すのは通常のチャットです。
    - D: 誤り。エージェントも FM で計画と判断を行います。

    **スキル:** [3.1.6](../domain3.md#obj-3-1-6) / **参照:** [エージェント](../../../services/ai-fundamentals.md#agents)

### 問9 {#q9}

業務での使い方として、エージェントが最も適しているものはどれですか。

- A. 文章を一度だけ別の言語に翻訳する
- B. 一定の書式のスキャン文書から文字と表を決まった形式で取り出す
- C. 決まった税率で税額を計算する
- D. 注文を調べ、条件を確認し、返品の手続きまで進める

??? success "答えと解説"
    **正解: D**

    複数の手順とツールの実行が必要な仕事にエージェントが向きます。

    - A: 誤り。手順を判断する必要がなく、翻訳のサービスで足ります。
    - B: 誤り。Textract のようなマネージド AI サービスが向きます。
    - C: 誤り。規則で計算できるので、通常のプログラムが向きます。
    - D: 正しい。

    **スキル:** [3.1.6](../domain3.md#obj-3-1-6) / **参照:** [エージェント](../../../services/ai-fundamentals.md#agents)

### 問10 {#q10}

エージェントが送金を実行できるようにします。安全のための対策として適切なものはどれですか。

- A. プロンプトで注意を促せば承認は不要になる
- B. 実行の前に人が承認する手順
- C. 権限を広げて失敗を減らす
- D. temperature を下げれば承認は不要になる

??? success "答えと解説"
    **正解: B**

    送金や削除のような影響の大きい操作は、人が承認してから実行します。

    - A: 誤り。プロンプトでの禁止は確実な防御ではありません。
    - B: 正しい。
    - C: 誤り。最小権限が原則で、広げるとリスクが増えます。
    - D: 誤り。不可逆な操作の安全は、temperature の調整では確保できません。

    **スキル:** [3.1.6](../domain3.md#obj-3-1-6) / **参照:** [安全な自律動作](../../../services/genai-apps.md#agent-safeguards)、[人による監督](../../../services/ai-fundamentals.md#human-oversight)

### 問11 {#q11}

新規にエージェントを本番で動かします。2026 年 10 月時点の公式の案内に沿った基盤はどれですか。

- A. Amazon Lex
- B. SageMaker Pipelines
- C. Bedrock Agents（Agents Classic）を新規に使い始める
- D. Amazon Bedrock AgentCore

??? success "答えと解説"
    **正解: D**

    Bedrock Agents は Agents Classic に改称され、新規のエージェントには AgentCore を使います。

    - A: 誤り。会話のインターフェイスを作るサービスで、エージェントの実行基盤ではありません。
    - B: 誤り。ML のワークフローを自動化する機能で、エージェントの実行基盤ではありません。
    - C: 誤り。新規顧客を受け付けていません。
    - D: 正しい。

    **スキル:** [3.1.6](../domain3.md#obj-3-1-6) / **参照:** [AgentCore のアーキテクチャ](../../../services/genai-apps.md#agentcore)、[Bedrock Agents（Classic）](../../../services/genai-apps.md#agents-classic)

### 問12 {#q12}

コードでエージェントの動きを書くオープンソースの SDK と、それを本番で動かす基盤の組み合わせはどれですか。

- A. Strands Agents と AgentCore
- B. Amazon Quick と AgentCore
- C. Kiro と SageMaker Pipelines
- D. Strands Agents と Amazon Lex

??? success "答えと解説"
    **正解: A**

    Strands はエージェントを書く道具で、AgentCore は動かす基盤です。

    - A: 正しい。
    - B: 誤り。Quick は業務ユーザー向けのアプリケーションで、コードで動きを書く SDK ではありません。
    - C: 誤り。Kiro は開発環境で、Pipelines は ML のワークフローの機能です。どちらもエージェントの SDK や実行基盤ではありません。
    - D: 誤り。Strands は合いますが、Lex は会話のインターフェイスを作るサービスで、エージェントの実行基盤ではありません。

    **スキル:** [2.3.1](../domain2.md#obj-2-3-1) / **参照:** [マルチエージェント](../../../services/genai-apps.md#multi-agent)、[AgentCore のアーキテクチャ](../../../services/genai-apps.md#agentcore)
