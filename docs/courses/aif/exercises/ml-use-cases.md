# AI/ML のユースケースの問題集

対象の解説: [学習の種類と手法の選び方](../../../services/ai-fundamentals.md#learning-types)、[AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)、[従来の ML と FM の使い分け](../../../services/ai-fundamentals.md#ml-vs-fm)

### 問1 {#q1}

毎日 100 万件届く商品レビューの感情を集計したいのですが、担当者が読むには量が多すぎます。AI/ML の主な価値はどれですか。

- A. 人が書いた規則より常に安く動き、費用の検討が要らない
- B. データがなくても判断できる
- C. 必ず正しい結果を保証できる
- D. 人では追いつかない量を処理できる

??? success "答えと解説"
    **正解: D**

    大量のデータを処理する拡張性は、AI/ML が価値を生む代表的な場面です。

    - A: 誤り。費用は条件によって変わり、常に安いとは言えません。
    - B: 誤り。データがなければ学習も評価もできません。
    - C: 誤り。ML の出力は予測で、誤りはなくなりません。
    - D: 正しい。

    **スキル:** [1.2.1](../domain1.md#obj-1-2-1) / **参照:** [ユースケースの選定と優先順位](../../../services/ai-fundamentals.md#use-case-prioritization)

### 問2 {#q2}

医師が画像を読むときに、AI が所見の候補と根拠を示し、最終判断は医師が行います。この AI の使い方が生む価値はどれですか。

- A. 人の判断を支援すること
- B. データの収集の省略
- C. 判断の完全な自動化
- D. 説明責任の AI への移転

??? success "答えと解説"
    **正解: A**

    候補や根拠を示して人が決める使い方は、人の判断の支援です。

    - A: 正しい。
    - B: 誤り。AI は十分なデータがあって初めて機能します。
    - C: 誤り。最終判断は医師が行っているので、完全な自動化ではありません。
    - D: 誤り。責任は人に残ります。AI に移すことはできません。

    **スキル:** [1.2.1](../domain1.md#obj-1-2-1) / **参照:** [ユースケースの選定と優先順位](../../../services/ai-fundamentals.md#use-case-prioritization)、[人による監督](../../../services/ai-fundamentals.md#human-oversight)

### 問3 {#q3}

AI/ML が特に向いている条件の組み合わせを選んでください。（2つ選択）

- A. 規則を書き切れないが、過去のデータは大量にある
- B. 期待される効果より、導入と運用の費用のほうが大きい
- C. 常に同じ結果が必要で、規則が明確に決まっている
- D. 関連するデータがほとんどなく、当面集める予定もない
- E. 多少の誤りを許容でき、繰り返しの作業を自動化したい

??? success "答えと解説"
    **正解: A, E**

    規則を書き切れない、データが豊富、多少の誤りを許容できる、の条件がそろうと AI が向きます。

    - A: 正しい。
    - B: 誤り。費用対効果が合わないので、実施しない判断になります。
    - C: 誤り。決定的な処理なので、ルールベースや通常のプログラムが向きます。
    - D: 誤り。学習が成り立たないので、先にデータの整備が必要です。
    - E: 正しい。

    **スキル:** [1.2.1](../domain1.md#obj-1-2-1) / **参照:** [AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)

### 問4 {#q4}

経理部門が、税率表に基づく消費税額の計算に ML を使うことを検討しています。適切な助言はどれですか。

- A. 回帰モデルを学習して税額を予測する
- B. 分類モデルで税率の区分を推定する
- C. 税率表を使う通常のプログラムで計算する
- D. 生成 AI に毎回計算させ、人が確かめる

??? success "答えと解説"
    **正解: C**

    確定した結果が必要で規則も明確なので、ML は適切ではありません。

    - A: 誤り。税額には予測ではなく確定した値が必要です。
    - B: 誤り。区分も規則で決まっているので、推定する理由がありません。
    - C: 正しい。
    - D: 誤り。規則が明確な処理に、応答がぶれるモデルと確認の手間を足すだけです。

    **スキル:** [1.2.2](../domain1.md#obj-1-2-2) / **参照:** [AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)

### 問5 {#q5}

月に数件しか発生しない小さな作業を AI で自動化する案が出ました。試算では、開発と運用の費用が削減額を大きく上回ります。適切な判断はどれですか。

- A. より大きなモデルを使って精度を上げる
- B. 費用対効果が合わないので実施しない
- C. 効果の測定を省いて先に導入する
- D. 学習データを増やして再度検討する

??? success "答えと解説"
    **正解: B**

    効果よりコストが大きいなら、AI を使わないのが正しい判断です。

    - A: 誤り。費用がさらに増え、問題を解決しません。
    - B: 正しい。
    - C: 誤り。費用が効果を上回ると分かっている案を進める理由がありません。
    - D: 誤り。作業の量が少ないという費用対効果の問題は解決しません。

    **スキル:** [1.2.2](../domain1.md#obj-1-2-2) / **参照:** [AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)

### 問6 {#q6}

「注文額が 5,000 円以上なら送料無料」という処理の実装として適切なものはどれですか。

- A. 教師なし学習のクラスタリング
- B. 教師あり学習の分類モデル
- C. ルールベースの条件分岐処理
- D. LLM への毎回の問い合わせ

??? success "答えと解説"
    **正解: C**

    規則を書き切れて常に同じ結果が必要なら、ルールベースを選びます。

    - A: 誤り。グループを見つける手法で、この判定には関係しません。
    - B: 誤り。規則が明確で、常に同じ結果が必要な処理に学習は不要です。
    - C: 正しい。
    - D: 誤り。応答がぶれるうえ、トークンの費用もかかります。

    **スキル:** [1.2.2](../domain1.md#obj-1-2-2) / **参照:** [AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)

### 問7 {#q7}

機械学習のチームが新規プロジェクトを検討しています。使えるデータは数十件だけで、欠損と重複が多い状態です。最初にすべきことはどれですか。

- A. 最も大きなモデルを選んで学習する
- B. ハイパーパラメータを細かく調整する
- C. そのまま本番にデプロイして様子を見る
- D. データを増やし、欠損と重複を整備する

??? success "答えと解説"
    **正解: D**

    データが少ない、または質が低いと学習が成り立たないので、まずデータを整備します。

    - A: 誤り。データの質が結果を決めるので、大きなモデルでは補えません。
    - B: 誤り。調整で補えるのはデータの不足ではありません。
    - C: 誤り。学習が成り立たない段階です。
    - D: 正しい。

    **スキル:** [1.2.2](../domain1.md#obj-1-2-2) / **参照:** [AI を使わない判断](../../../services/ai-fundamentals.md#when-not-ai)、[データ品質と不均衡](../../../services/ai-fundamentals.md#data-quality)

### 問8 {#q8}

物件の広さや立地から、住宅の価格を予測します。適切な手法はどれですか。

- A. 回帰
- B. クラスタリング
- C. 次元削減
- D. 分類

??? success "答えと解説"
    **正解: A**

    出力が数値なら回帰です。

    - A: 正しい。
    - B: 誤り。正解なしでグループを作る手法です。
    - C: 誤り。列を減らす手法で、価格の予測そのものではありません。
    - D: 誤り。出力がクラスの場合の手法です。

    **スキル:** [1.2.3](../domain1.md#obj-1-2-3) / **参照:** [問題の種類](../../../services/ai-fundamentals.md#problem-types)

### 問9 {#q9}

問い合わせのメールを「請求」「技術」「解約」など 5 種類に自動で振り分けます。過去のメールには振り分け先の正解が付いています。適切な手法はどれですか。

- A. 二値分類
- B. 多クラス分類
- C. 回帰
- D. クラスタリング

??? success "答えと解説"
    **正解: B**

    正解付きのデータで 3 種類以上のクラスに分けるのは多クラス分類です。

    - A: 誤り。2 種類に分ける場合の手法です。
    - B: 正しい。
    - C: 誤り。出力が数値の場合の手法です。
    - D: 誤り。正解がなくグループを見つける場合の手法です。

    **スキル:** [1.2.3](../domain1.md#obj-1-2-3) / **参照:** [問題の種類](../../../services/ai-fundamentals.md#problem-types)

### 問10 {#q10}

会員の購買履歴から、似た顧客のグループを作ってキャンペーンに使います。あらかじめ決まったグループやラベルはありません。適切な手法はどれですか。

- A. 二値分類
- B. クラスタリング
- C. 回帰
- D. 時系列予測

??? success "答えと解説"
    **正解: B**

    正解なしで似たものをまとめるのはクラスタリングです。

    - A: 誤り。正解のラベルが必要です。
    - B: 正しい。
    - C: 誤り。数値を予測する手法で、グループを作るものではありません。
    - D: 誤り。将来の数値を予測する手法です。

    **スキル:** [1.2.3](../domain1.md#obj-1-2-3) / **参照:** [問題の種類](../../../services/ai-fundamentals.md#problem-types)

### 問11 {#q11}

銀行が融資の可否を判定します。規制当局に否決の理由を説明する必要があり、同じ申請には同じ結果を返したいと考えています。主に使うものとして適切なのはどれですか。

- A. 画像生成の拡散モデル
- B. 最も高性能な FM に判定を任せる
- C. 解釈しやすい従来の ML モデル
- D. 高い temperature を設定した LLM

??? success "答えと解説"
    **正解: C**

    説明可能性と再現性が必要な判定には、解釈しやすい従来の ML が向きます。

    - A: 誤り。画像を作るモデルで、この判定とは関係しません。
    - B: 誤り。FM は応答がぶれやすく、内部の説明も難しいので、補助に留めます。
    - C: 正しい。
    - D: 誤り。応答のばらつきが増え、要件と逆です。

    **スキル:** [1.2.6](../domain1.md#obj-1-2-6) / **参照:** [従来の ML と FM の使い分け](../../../services/ai-fundamentals.md#ml-vs-fm)

### 問12 {#q12}

長い契約書を読んで要点をまとめ、担当者の質問にも自然文で答える機能を作ります。ラベル付きのデータはなく、すぐに試したいと考えています。適切なものはどれですか。

- A. Bedrock の FM
- B. 線形回帰
- C. k-means クラスタリング
- D. 決定木

??? success "答えと解説"
    **正解: A**

    文章、対話が得意で、API ですぐ試せるのが FM です。

    - A: 正しい。
    - B: 誤り。表データから数値を予測する手法です。
    - C: 誤り。データをグループに分ける手法で、文章の要約や対話はできません。
    - D: 誤り。表データの判定に向く手法で、文章の生成はできません。

    **スキル:** [1.2.6](../domain1.md#obj-1-2-6) / **参照:** [従来の ML と FM の使い分け](../../../services/ai-fundamentals.md#ml-vs-fm)

### 問13 {#q13}

従来の ML と FM を比較した説明として正しいものはどれですか。

- A. 従来の ML は文章の生成と対話が最も得意である
- B. 従来の ML は学習データが不要で、すぐ試せる
- C. FM は常に同じ入力に同じ出力を返し、説明もしやすい
- D. FM はすぐ試せるが、同じ入力でも応答がぶれやすい

??? success "答えと解説"
    **正解: D**

    運用の制約、再現性、説明可能性の違いで使い分けます。

    - A: 誤り。従来の ML が得意なのは表データの予測です。
    - B: 誤り。従来の ML は自社のラベル付きデータと学習の運用が必要です。
    - C: 誤り。FM は非決定的で、説明可能性は低いと考えます。
    - D: 正しい。

    **スキル:** [1.2.6](../domain1.md#obj-1-2-6) / **参照:** [従来の ML と FM の使い分け](../../../services/ai-fundamentals.md#ml-vs-fm)
