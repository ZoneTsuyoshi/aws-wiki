# 問題集

話題ごとの本番形式の問題です。**AIF-C01** の試験ガイド（第 1.2 版）を基準にしています。すべてオリジナルの問題で、実際の試験問題ではありません。答えは問題の下を開くと確認でき、選択肢ごとの解説と解説ページへのリンクがあります。

1. まず[分野のページ](../index.md#study-path)で範囲を確認します。
2. サービスの解説を読み、問題を解きます。
3. 間違えた問題は、解説のリンク先に戻って確認します。

実際の試験には並べ替えと組み合わせの形式もあります。この問題集では、順番や対応を択一と複数選択の形で確かめます。
