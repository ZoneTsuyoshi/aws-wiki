# AWS の生成 AI サービスの問題集

対象の解説: [AWS の AI の 3 階層](../../../services/ai-managed-services.md#three-layers)、[アプリから Bedrock を呼ぶ](../../../services/ai.md#bedrock-runtime)、[データプライバシー](../../../services/ai.md#data-privacy)

### 問1 {#q1}

インスタンスを管理せず、複数の FM を同じ API で試したいと考えています。適切なサービスはどれですか。

- A. Amazon Bedrock
- B. SageMaker JumpStart
- C. AWS Glue
- D. Amazon Rekognition

??? success "答えと解説"
    **正解: A**

    Bedrock は複数の FM を API で使えるサービスで、インスタンスの管理は要りません。

    - A: 正しい。
    - B: 誤り。自分のアカウントのインスタンスで動かすので、インスタンスの管理が必要です。
    - C: 誤り。データの準備に使うサービスです。
    - D: 誤り。画像と動画を分析するサービスです。

    **スキル:** [2.3.1](../domain2.md#obj-2-3-1) / **参照:** [アプリから Bedrock を呼ぶ](../../../services/ai.md#bedrock-runtime)

### 問2 {#q2}

事前学習済みモデルのハブから FM を選び、自分のインスタンスにすぐデプロイしたいと考えています。適切な機能はどれですか。

- A. Amazon Bedrock Guardrails
- B. AWS Config
- C. SageMaker JumpStart
- D. Amazon Quick

??? success "答えと解説"
    **正解: C**

    JumpStart は事前学習済みモデルのハブで、自分のアカウントにデプロイします。

    - A: 誤り。入出力を検査する機能です。
    - B: 誤り。リソースの設定を記録して評価するサービスです。
    - C: 正しい。
    - D: 誤り。業務ユーザー向けのアプリケーションです。

    **スキル:** [2.3.1](../domain2.md#obj-2-3-1) / **参照:** [JumpStart](../../../services/sagemaker.md#jumpstart)

### 問3 {#q3}

AWS の AI の 3 階層のうち、ML プラットフォームの階層にあり、最も細かく制御できるものはどれですか。

- A. Amazon Comprehend
- B. Kiro
- C. Amazon Quick
- D. Amazon SageMaker AI

??? success "答えと解説"
    **正解: D**

    アプリケーション、AI サービスと FM、ML プラットフォームの順に制御が大きくなります。

    - A: 誤り。AI サービスの階層で、学習済みの機能を呼びます。
    - B: 誤り。アプリケーションの階層で、開発者向けの環境です。
    - C: 誤り。アプリケーションの階層で、制御は最も小さくなります。
    - D: 正しい。

    **スキル:** [2.3.1](../domain2.md#obj-2-3-1) / **参照:** [AWS の AI の 3 階層](../../../services/ai-managed-services.md#three-layers)

営業部門の担当者が、コードを書かずに、社内の文書とデータをもとに調査レポートを作りたいと考えています。適切なサービスはどれですか。

- A. SageMaker AI
- B. Amazon Quick
- C. AgentCore Runtime
- D. Strands Agents

    - B: 正しい。
    - C: 誤り。エージェントをデプロイする実行基盤です。
    - D: 誤り。コードでエージェントを書く SDK です。

    **スキル:** [2.3.1](../domain2.md#obj-2-3-1) / **参照:** [Amazon Quick](../../../services/ai.md#quick)

### 問5 {#q5}

生成 AI アプリの部品と役割の組み合わせとして正しいものを選んでください。（2つ選択）

- A. SageMaker JumpStart: S3 の機密データを発見する
- B. AgentCore: エージェントの実行基盤、記憶、ツール接続を提供する
- C. Strands Agents: 業務ユーザーがコードなしで使う分析アプリケーションである
- D. Amazon Quick: FM の重みを学習する基盤である
- E. Kiro: 仕様駆動で開発を AI に支援させる

??? success "答えと解説"
    **正解: B, E**

    それぞれのサービスが、誰のための何の部品かを押さえます。

    - A: 誤り。それは Macie の役割です。
    - B: 正しい。
    - C: 誤り。コードでエージェントを作るオープンソースの SDK です。
    - D: 誤り。業務ユーザー向けのアプリケーションです。
    - E: 正しい。

### 問6 {#q6}

ML の専門家がいない部門でも、Bedrock の API で複数のモデルを試して PoC を作れました。この例が示す利点はどれですか。

- A. 参入障壁の低さと市場投入の速さ
- B. インスタンスの詳細な制御
- C. ハルシネーションが完全に解消されること
- D. 最大のモデルの必須化

??? success "答えと解説"
    **正解: A**

    専門家がいなくても始められ、学習せずに素早く作れます。

    - A: 正しい。
    - B: 誤り。Bedrock はインスタンスを管理しないので、詳細な制御が利点ではありません。
    - C: 誤り。使うサービスに関係なく、ハルシネーションはなくなりません。
    - D: 誤り。用途に合うモデルを選べるのが利点です。

    **スキル:** [2.3.2](../domain2.md#obj-2-3-2) / **参照:** [マネージド AI サービスと Bedrock](../../../services/ai-managed-services.md#vs-bedrock)、[作る、買う、組む](../../../services/ai-fundamentals.md#build-buy-partner)

### 問7 {#q7}

基盤の管理が不要で、使った分だけ支払える点は、AWS の生成 AI サービスのどの利点に当たりますか。

- A. 出力の正しさの保証
- B. 効率と費用対効果
- C. データの所在の自動的な保証
- D. 責任共有モデルの免除

??? success "答えと解説"
    **正解: B**

    インスタンスの管理をせず、オンデマンドのトークン課金で使える点を指します。

    - A: 誤り。出力の検証は利用者の責任です。
    - B: 正しい。
    - C: 誤り。リージョンや推論プロファイルは利用者が選びます。
    - D: 誤り。利用者のデータや権限の責任はなくなりません。

    **スキル:** [2.3.2](../domain2.md#obj-2-3-2) / **参照:** [マネージド AI サービスと Bedrock](../../../services/ai-managed-services.md#vs-bedrock)

### 問8 {#q8}

自社のアプリで FM を切り替えながら評価し、用途に最も合うものを選べました。これが示す利点はどれですか。

- A. プロンプトの設計が不要になること
- B. 評価を省略できること
- C. モデルの提供者の責任で業務の成果が保証されること
- D. 事業目標に合うモデルと機能を選べること

??? success "答えと解説"
    **正解: D**

    用途に合うモデルと機能を選べることは、事業目標の達成につながります。

    - A: 誤り。プロンプトの設計は引き続き必要です。
    - B: 誤り。評価してから切り替えています。
    - C: 誤り。業務の成果は自社で確かめる必要があります。
    - D: 正しい。

    **スキル:** [2.3.2](../domain2.md#obj-2-3-2) / **参照:** [マネージド AI サービスと Bedrock](../../../services/ai-managed-services.md#vs-bedrock)

### 問9 {#q9}

Bedrock に送るプロンプトの扱いについて、セキュリティ部門から質問がありました。正しい説明はどれですか。

- A. オプトアウトを設定しないと、学習に使われる
- B. PrivateLink を使わないと、学習に使われる
- C. モデルの学習に使われず、モデルの提供者とも共有されない
- D. モデルの提供者に共有され、提供者の次のモデルの学習に使われる

??? success "答えと解説"
    **正解: C**

    Bedrock は入出力をモデルの学習に使わず、モデルの提供者とも共有しません。一部のモデルでは不正利用の検知のために AWS が最長 30 日保持しますが、この場合も提供者には渡しません。

    - A: 誤り。Bedrock はオプトアウトの設定に関係なく学習に使いません。
    - B: 誤り。PrivateLink が守るのは通信経路で、学習の利用とは別の話です。
    - C: 正しい。
    - D: 誤り。共有も学習への利用もされません。

    **スキル:** [2.3.3](../domain2.md#obj-2-3-3) / **参照:** [入出力は学習に使われるか](../../../services/ai.md#training-use)

### 問11 {#q11}

責任共有モデルで、Bedrock を使う利用者の担当に当たるものを選んでください。（2つ選択）

- A. FM の運用の基盤
- B. データセンターの物理的な保護
- C. アクセス権の設定
- D. サービスのハードウェアの保守
- E. ガードレールの設定

??? success "答えと解説"
    **正解: C, E**

    AWS は基盤とサービスを、利用者はデータ、権限、プロンプト、ガードレールの設定、アプリを担当します。

    - A: 誤り。AWS の担当です。
    - B: 誤り。AWS の担当です。
    - C: 正しい。
    - D: 誤り。AWS の担当です。
    - E: 正しい。

    **スキル:** [2.3.3](../domain2.md#obj-2-3-3) / **参照:** [責任共有モデル](../../../services/ai-fundamentals.md#shared-responsibility)

### 問12 {#q12}

AWS の基盤を使うときの安全性の利点の例として正しいものはどれですか。

- A. IAM を設定しなくても全員が安全に使える
- B. 利用者がプロンプトや出力を検証する必要がすべてなくなる
- C. Guardrails で有害な内容や機密情報を制御できる
- D. 誤った回答を AWS が自動で訂正する

??? success "答えと解説"
    **正解: C**

    AWS の機能を使って、利用者が保護の設定を行います。

    - A: 誤り。アクセス権の設定は利用者の担当です。
    - B: 誤り。入力と出力の扱いは利用者の責任に残ります。
    - C: 正しい。
    - D: 誤り。回答の正しさの検証は利用者が行います。

    **スキル:** [2.3.3](../domain2.md#obj-2-3-3) / **参照:** [Guardrails](../../../services/ai.md#guardrails)
