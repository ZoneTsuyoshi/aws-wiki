# パートナーと Marketplace の問題集

対象の解説: [クラウドの基礎](../../../services/cloud-foundations.md)、[ガバナンス](../../../services/governance.md)

### 問1 {#q1}

自社のソフトウェアを AWS Marketplace で SaaS として販売する企業は、AWS Partner Network のどの種類に当たりますか。

- A. 独立系ソフトウェアベンダー（ISV）
- B. ソリューションアーキテクト
- C. テクニカルアカウントマネージャー
- D. システムインテグレーター

??? success "答えと解説"
    **正解: A**

    ISV は自社のソフトウェアを提供します。

    - A: 正しい。
    - B: 誤り。設計の相談の担当者で、企業の種類ではない。
    - C: 誤り。サポートプランの専任の担当者で、企業の種類ではない。
    - D: 誤り。構築や移行を請け負う企業。

    **スキル:** [AWS Partner Network](../domain4.md#t4-3-apn) / **参照:** [サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問2 {#q2}

顧客のシステムの AWS への移行を請け負う企業は、どの種類に当たりますか。

- A. AWS Support
- B. 独立系ソフトウェアベンダー（ISV）
- C. システムインテグレーター
- D. AWS Trust & Safety

??? success "答えと解説"
    **正解: C**

    システムインテグレーターは構築や移行を請け負います。

    - A: 誤り。AWS の相談窓口で、パートナーの種類ではない。
    - B: 誤り。自社のソフトウェアを提供する企業。
    - C: 正しい。
    - D: 誤り。悪用の報告の窓口。

    **スキル:** [AWS Partner Network](../domain4.md#t4-3-apn) / **参照:** [サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問3 {#q3}

AWS Partner Network と AWS Marketplace の関係の説明として正しいものはどれですか。

- A. Marketplace はパートナーへの研修の専用の場である
- B. Marketplace は、パートナーが顧客に製品を販売する場でもある
- C. Marketplace を使えるのは、パートナーだけで顧客は購入できない
- D. パートナーは Marketplace で製品を販売してはいけない

??? success "答えと解説"
    **正解: B**

    APN は AWS と協力する企業のプログラムです。

    - A: 誤り。製品のカタログで、研修の場ではない。
    - B: 正しい。
    - C: 誤り。顧客は製品を探して購入できる。
    - D: 誤り。パートナーの販売の場である。

    **スキル:** [AWS Partner Network](../domain4.md#t4-3-apn) / **参照:** [AWS Marketplace](../../../services/cloud-foundations.md#marketplace)、[サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問4 {#q4}

試験ガイドが挙げる、AWS Partner になる利点の例はどれですか。（2つ選択）

- A. AWS の料金の永久無料
- B. 顧客のルートユーザーの管理の権限
- C. パートナー向けの研修と認定
- D. パートナーのイベント
- E. AWS の責任共有モデルの適用外

??? success "答えと解説"
    **正解: C, D**

    ガイドの例は、研修と認定、イベント、ボリューム割引です。

    - A: 誤り。利点に挙げられていない。
    - B: 誤り。利点に挙げられていない。
    - C: 正しい。
    - D: 正しい。
    - E: 誤り。利点に挙げられていない。

    **スキル:** [AWS Partner になる利点](../domain4.md#t4-3-partner-benefits) / **参照:** [サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問5 {#q5}

試験ガイドが挙げる、AWS Partner になる利点に含まれる料金面の例はどれですか。

- A. 全サービスの料金の永久無料
- B. データ転送の送信の完全な無料化
- C. 一括請求の追加料金の免除
- D. ボリューム割引

??? success "答えと解説"
    **正解: D**

    ガイドは例としてボリューム割引を挙げています。

    - A: 誤り。挙げられていない。
    - B: 誤り。挙げられていない。
    - C: 誤り。一括請求に追加料金はそもそもかからない。
    - D: 正しい。

    **スキル:** [AWS Partner になる利点](../domain4.md#t4-3-partner-benefits) / **参照:** [サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問6 {#q6}

公式のパートナーのページで案内されている内容に当たるものはどれですか。

- A. 他社の AWS アカウントの閲覧の権限
- B. 顧客の監査レポートの自動作成
- C. パートナーへの AWS の利用料金の全額の免除と永久の割引
- D. ウェビナーやイベント、販売を支援するプログラム

??? success "答えと解説"
    **正解: D**

    研修、イベント、販売の支援、Marketplace での販売が案内されています。

    - A: 誤り。案内されていない。
    - B: 誤り。案内されていない。
    - C: 誤り。案内されていない。
    - D: 正しい。

    **スキル:** [AWS Partner になる利点](../domain4.md#t4-3-partner-benefits) / **参照:** [サポートの情報源](../../../services/cloud-foundations.md#support-resources)

### 問7 {#q7}

AWS Marketplace の説明として正しいものはどれですか。

- A. AWS の監査レポートをダウンロードするためのカタログ
- B. 自社のコンテナイメージを非公開で保管する場所
- C. サードパーティのソフトウェアを購入できるカタログ
- D. AWS の障害の情報をまとめたダッシュボード

??? success "答えと解説"
    **正解: C**

    料金は AWS の請求書に合算されます。

    - A: 誤り。それは AWS Artifact。
    - B: 誤り。それは Amazon ECR。
    - C: 正しい。
    - D: 誤り。それは AWS Health Dashboard。

    **スキル:** [AWS Marketplace の主な機能](../domain4.md#t4-3-marketplace) / **参照:** [AWS Marketplace](../../../services/cloud-foundations.md#marketplace)

### 問8 {#q8}

組織で購入できる Marketplace の製品を、承認済みのものに絞りたいと考えています。最も適切な機能はどれですか。

- A. AWS Trusted Advisor
- B. Private Marketplace
- C. コスト配分タグ
- D. AWS Budgets

??? success "答えと解説"
    **正解: B**

    Private Marketplace は、ガバナンスの機能です。

    - A: 誤り。環境の点検のサービス。
    - B: 正しい。
    - C: 誤り。費用の分類の仕組みで、購入の制限はできない。
    - D: 誤り。費用のしきい値の通知で、製品を絞らない。

    **スキル:** [AWS Marketplace の主な機能](../domain4.md#t4-3-marketplace) / **参照:** [AWS Marketplace](../../../services/cloud-foundations.md#marketplace)

### 問9 {#q9}

Marketplace で購入したソフトウェアのライセンスを、組織のアカウントに配布したいと考えています。最も適切なサービスはどれですか。

- A. AWS License Manager
- B. AWS Artifact
- C. AWS Budgets
- D. AWS Organizations の SCP

??? success "答えと解説"
    **正解: A**

    購入するとライセンスが作られ、License Manager で配布できます。

    - A: 正しい。
    - B: 誤り。監査レポートと契約の入手先。
    - C: 誤り。費用のしきい値を通知するサービス。
    - D: 誤り。使える操作の上限を決める仕組みで、ライセンスの配布は行わない。

    **スキル:** [AWS Marketplace の主な機能](../domain4.md#t4-3-marketplace) / **参照:** [AWS Marketplace](../../../services/cloud-foundations.md#marketplace)、[AWS License Manager](../../../services/governance.md#license-manager)

### 問10 {#q10}

Marketplace の費用の管理に役立つ機能はどれですか。（2つ選択）

- A. ゾーナル RI の容量の確保
- B. AWS Health API の連携
- C. コスト配分タグでの費用の追跡
- D. AWS Compute Optimizer のサイズの提案
- E. Procurement insights ダッシュボード

??? success "答えと解説"
    **正解: C, E**

    Procurement insights で組織全体の費用と契約を確認でき、コスト配分タグで費用を追跡できます。Private Marketplace は費用ではなくガバナンスの機能です。

    - A: 誤り。Marketplace の機能ではない。
    - B: 誤り。Marketplace の機能ではない。
    - C: 正しい。
    - D: 誤り。EC2 などのサイズを提案するサービスで、Marketplace の機能ではない。
    - E: 正しい。

    **スキル:** [AWS Marketplace の主な機能](../domain4.md#t4-3-marketplace) / **参照:** [AWS Marketplace](../../../services/cloud-foundations.md#marketplace)
