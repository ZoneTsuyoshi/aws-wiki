# 分野4: パートナーと Marketplace

パートナーの種類と利点、Marketplace の機能を問います。

## 問われるスキル {#skills}

| スキル | 内容 |
|---|---|
| [AWS Partner Network](../../domain4.md#t4-3-apn) | ISV とシステムインテグレーター |
| [AWS Partner になる利点](../../domain4.md#t4-3-partner-benefits) | 研修と認定、イベント、ボリューム割引 |
| [AWS Marketplace の主な機能](../../domain4.md#t4-3-marketplace) | 費用管理、ガバナンス、権利 |

## 学習の順番 {#study-order}

1. [サポートの情報源](../../../../services/cloud-foundations.md#support-resources): APN の位置づけを確認します。
2. [AWS Marketplace](../../../../services/cloud-foundations.md#marketplace): カタログの特徴を確認します。
3. [AWS License Manager](../../../../services/governance.md#license-manager): 購入したライセンスの配布先を確認します。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 自社のソフトウェアを販売する | ISV |
| 顧客のシステムの移行を請け負う | システムインテグレーター |
| 購入できる製品を承認済みに絞る | Private Marketplace |
| 組織の Marketplace の費用と契約を確認する | Procurement insights ダッシュボード |
| 購入したライセンスを配布する | AWS License Manager |

## 引っかかりやすい点 {#traps}

- Marketplace は顧客が購入する場で、パートナーが販売する場でもあります。
- Marketplace の料金は AWS の請求書に合算されます。
- 技術支援の TAM やソリューションアーキテクトは、パートナーの種類ではありません。
