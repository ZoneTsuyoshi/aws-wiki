## 覚える値 {#values}

| 項目 | 値 | 判断のポイント |
|---|---|---|
| クラウドの利点 | 6 つ | 固定費の変動費化、規模の経済、容量の推測の不要、速度と俊敏性、データセンターの運用の廃止、世界展開 |

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| サーバーを先に買いたくない | 固定費を変動費に変える |
| 需要が読めない | 容量の推測が不要になる |
| ラックや電源の管理をやめたい | データセンターの運用をやめる |
| 海外の利用者の近くにすぐ置きたい | 数分で世界に展開する |
| AZ の障害でも止まらない | 高可用性 |
| 夜間は台数を減らす | 弾力性 |
| 検証環境を数分で作って捨てる | 俊敏性 |

## 引っかかりやすい点 {#traps}

- 弾力性と高可用性を混同しがちです。負荷に合わせた増減は弾力性、故障しても動き続けるのは高可用性です。
- 俊敏性は試すまでの速さで、処理の速さではありません。
- どのリージョンに置くかは利用者が決めます。自動では複製されません。
