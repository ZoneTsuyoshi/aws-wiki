## 覚える値 {#values}

| 項目 | 値 | 判断のポイント |
|---|---|---|
| アクセスキー | 1 ユーザーにつき 2 つ | 長期の認証情報 |
| パスワードの既定 | 8〜128 文字、3 種類以上、期限なし | ルートとアクセスキーは対象外 |
| カスタムの最小の長さ | 6〜128 文字 | |
| パスワードの有効期限 | 1〜1,095 日 | |
| 再利用の禁止 | 過去 1〜24 個 | |
| ルートの MFA | 最大 8 台 | 初回サインインの試行から 14 日以内に登録 |

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| EC2 上のアプリから S3 を読む | ロール |
| 同じ権限を複数の人に与える | グループ |
| 複数のロールで同じ絞った権限を使う | カスタマー管理ポリシー |
| 社員が複数のアカウントへサインインする | IAM Identity Center |
| アプリの一般の利用者がサインインする | Amazon Cognito |
| 他のアカウントのリソースを一時的に操作する | クロスアカウント IAM ロール |
| 資格情報を自動でローテーションする | AWS Secrets Manager |
| 低リスクの設定値を無料で置く | Parameter Store のスタンダード |

## 引っかかりやすい点 {#traps}

- アカウント名や連絡先、利用するリージョンの変更に、ルートは不要です。古い教材と異なる部分があります。
- メールアドレスの変更やアカウントの閉鎖でルートが必要なのは、組織に属さないアカウントです。
- パスワードポリシーは、ルートのパスワードとアクセスキーに適用されません。
- ルートのメールアドレスは、個人ではなくグループのアドレスにします。
