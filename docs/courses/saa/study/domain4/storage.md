## 覚える値 {#values}

| 項目 | 値 | 判断のポイント |
|---|---|---|
| RDS の自動スケーリング | 空きが 10% 以下で 5 分以上続くなど | 増えるだけで減らない |

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 再作成できる共有データを安く | EFS One Zone |
| アクセスの少ないファイルが多い EFS | IA と Archive へのライフサイクル |
| 順次の大きなログ | `st1` |
| 使っていない容量の EBS | 小さなボリュームへ移す |
| 増加の読めない RDS | ストレージの自動スケーリング |

## 引っかかりやすい点 {#traps}

- EBS は確保した容量で課金され、減らせません。
- HDD はブートボリュームにできません。
- Aurora のクラスターボリュームは自動で増減します。
