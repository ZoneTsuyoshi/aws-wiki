# IAM とネットワークの権限の問題集

対象の解説: [IAM と STS](../../../services/iam.md)、[セキュリティグループのルール](../../../services/networking.md#security-group-rules)

### 問1 {#q1}

Glue ジョブから RDS へ接続します。接続元の IP は変わります。RDS のセキュリティグループの設定として適切なものはどれですか。

- A. Glue のセキュリティグループを送信先に、アウトバウンドの全 TCP を許可する
- B. 戻りの通信のために、エフェメラルポートのインバウンドを別に許可する
- C. すべての IP の範囲を送信元に、データベースのポートを許可する
- D. Glue のセキュリティグループを送信元に、データベースのポートを許可する

??? success "答えと解説"
    **正解: D**

    CIDR より、セキュリティグループの参照を使います。

    - A: 誤り。接続先のインバウンドの許可が要ります。
    - B: 誤り。セキュリティグループはステートフルです。
    - C: 誤り。不要に公開します。
    - D: 正しい。

    **スキル:** [4.1.1](../domain4.md#skill-4-1-1) / **参照:** [セキュリティグループのルール](../../../services/networking.md#security-group-rules)

### 問2 {#q2}

MSK のクライアントが IAM 認証で接続できません。VPC 内の接続で、セキュリティグループに許可するブローカーのポートはどれですか。

- A. 9092
- B. 9098
- C. 9096
- D. 9094

??? success "答えと解説"

    - A: 誤り。平文のポートです。
    - B: 正しい。
    - C: 誤り。SASL/SCRAM のポートです。
    - D: 誤り。TLS のポートです。

    **スキル:** [4.1.1](../domain4.md#skill-4-1-1) / **参照:** [Amazon MSK](../../../services/data-engineering.md#msk)、[セキュリティグループのルール](../../../services/networking.md#security-group-rules)

### 問3 {#q3}

接続できないときの確認で正しいものはどれですか。（2つ選択）

- A. EFS は 2049 番を Lambda のセキュリティグループから許可しているか
- B. S3 のバケットポリシーで EFS のポートを許可しているか
- C. VPC 内の Glue ジョブの自己参照のルールがあるか
- D. Redshift のセキュリティグループで Glue の IAM ロールの ARN を許可しているか
- E. 戻りの通信の許可をインバウンドに別途追加しているか

??? success "答えと解説"
    **正解: A, C**

    - A: 正しい。NFS のポートです。
    - B: 誤り。関係しません。
    - C: 正しい。部品同士の通信に必要です。

### 問4 {#q4}

データアナリスト 30 人に同じ権限を付けます。Glue のジョブには S3 の権限を渡します。正しい組み合わせはどれですか。

- A. 人には IAM ロールのアクセスキー、Glue のジョブには IAM ユーザーのキーを使う
- B. 人にはサービスリンクロール、Glue のジョブには root のキーを使う
- C. 人には IAM グループ、Glue のジョブには IAM ロールを使う
- D. 人には個別のインラインポリシー、Glue のジョブには IAM グループを使う

??? success "答えと解説"
    **正解: C**

    人はグループ、サービスはロールです。

    - A: 誤り。サービスには長期のキーを使いません。
    - B: 誤り。役割が合いません。
    - C: 正しい。
    - D: 誤り。グループはサービスに引き受けられません。

    **スキル:** [4.1.2](../domain4.md#skill-4-1-2) / **参照:** [プリンシパルと権限の定義](../../../services/iam.md#principals)、[サービスロールとサービスリンクロール](../../../services/iam.md#service-linked-roles)

使っていない権限を見つけ、バケットの外部からのアクセスも検出します。何を使いますか。

- A. AWS Config のアグリゲーターのみ
- B. IAM Access Analyzer
- C. Macie の自動検出のみ
- D. Glue Data Quality のみ

??? success "答えと解説"
    **正解: B**

    不要な権限と外部アクセスを見つけられます。

    - A: 誤り。設定の集約です。
    - B: 正しい。
    - C: 誤り。機密データの検出です。
    - D: 誤り。データの品質です。
