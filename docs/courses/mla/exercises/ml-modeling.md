# モデルの選択と基本の調整の問題集

対象の解説: [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)、[過学習](../../../services/ai-fundamentals.md#overfitting)、[アンサンブル](../../../services/ai-fundamentals.md#ensembles)

### 問1 {#q1}

数千の店舗の日次の売上を予測します。店舗ごとの系列は似ていて、全体をまとめて学習したいです。どの組み込みアルゴリズムを選びますか。

- A. K-Means
- B. Random Cut Forest
- C. DeepAR
- D. LDA

??? success "答えと解説"
    **正解: C**

    似た系列が多い需要予測には DeepAR が向きます。

    - A: 誤り。グループ分けのアルゴリズムで、将来の値を予測しません。
    - B: 誤り。異常検知のアルゴリズムです。
    - C: 正しい。
    - D: 誤り。文章の話題を教師なしで見つけるアルゴリズムです。

    **スキル:** [2.1.3](../domain2.md#skill-2-1-3) / **参照:** [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)

### 問2 {#q2}

広告のクリックを予測します。ユーザー ID と広告 ID の組み合わせによる、高次元で疎なデータです。どのアルゴリズムが適していますか。

- A. DeepAR
- B. Factorization Machines
- C. BlazingText
- D. K-Means

??? success "答えと解説"
    **正解: B**

    高次元の疎データとクリック予測には Factorization Machines が向きます。

    - A: 誤り。時系列の予測に使います。
    - B: 正しい。
    - C: 誤り。テキストの分類や単語埋め込みに使います。
    - D: 誤り。教師なしのグループ分けです。

    **スキル:** [2.1.3](../domain2.md#skill-2-1-3) / **参照:** [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)

### 問3 {#q3}

融資の審査で、規制により否決の理由の説明が必須です。深層学習モデルの精度は 1 ポイントだけ高い状況です。適切なモデルの選択はどれですか。（2つ選択）

- A. 決定木系のモデルと SHAP
- B. 精度を最優先して深層学習を選ぶ
- C. Linear Learner
- D. K-Means で顧客を分け、グループの番号を伝える
- E. FM の応答に否決の理由を自由に書かせる

??? success "答えと解説"
    **正解: A, C**

    解釈可能性が必須なら Linear Learner や決定木系と SHAP を選びます。わずかな精度より説明を優先します。

    - A: 正しい。特徴量ごとの寄与を説明できます。
    - B: 誤り。説明の要件を満たせず、差もわずかです。
    - C: 正しい。解釈しやすいモデルです。
    - D: 誤り。否決の理由の説明になりません。
    - E: 誤り。根拠のある説明になりません。

    **スキル:** [2.1.3](../domain2.md#skill-2-1-3) / **参照:** [説明可能性](../../../services/ai-fundamentals.md#explainability)、[組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)

### 問4 {#q4}

Linear Learner に学習データを渡します。受け付ける入力形式の組み合わせはどれですか。

- A. CSV と recordIO-protobuf
- B. JPEG と PNG
- C. Parquet と Avro だけ
- D. JSONL の会話形式だけ

??? success "答えと解説"
    **正解: A**

    Linear Learner は CSV と recordIO-protobuf を受け付けます。

    - A: 正しい。
    - B: 誤り。画像の形式です。
    - C: 誤り。Linear Learner の形式として示されているのは CSV と recordIO-protobuf です。
    - D: 誤り。Bedrock のカスタマイズの形式です。

    **スキル:** [2.2.1](../domain2.md#skill-2-2-1) / **参照:** [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)

### 問5 {#q5}

K-Means の学習ジョブのインスタンスを選びます。コストを無駄にしない選択はどれですか。

- A. GPU のインスタンスを必ず使う
- B. Inferentia のインスタンスを使う
- C. Trainium のインスタンスで Neuron コンパイルをする
- D. `ml.m5` などの CPU のインスタンスを使う

??? success "答えと解説"
    **正解: D**

    K-Means は CPU が推奨です。組み込みアルゴリズムでは入力形式とインスタンスの種類を確認します。

    - A: 誤り。K-Means は CPU が推奨です。
    - B: 誤り。Inferentia は推論向けです。
    - C: 誤り。深層学習の学習向けで、K-Means には不要です。
    - D: 正しい。

    **スキル:** [2.2.1](../domain2.md#skill-2-2-1) / **参照:** [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)

### 問6 {#q6}

scikit-learn の独自の前処理とモデルのコードがあります。独自のコンテナは作りたくありません。最も手間の小さい方法はどれですか。

- A. EC2 に scikit-learn をインストールして手で実行する
- B. ゼロから Dockerfile を書き、ECR へプッシュする
- C. AWS のフレームワークのコンテナで、スクリプトモードを使う
- D. 組み込みの XGBoost を選び、scikit-learn のコードは捨てる

??? success "答えと解説"
    **正解: C**

    scikit-learn、PyTorch、TensorFlow はフレームワークのコンテナで動かします。組み込みに合わなければスクリプトモードに進みます。

    - A: 誤り。SageMaker AI の管理機能を使えず、手間が増えます。
    - B: 誤り。手間が大きく、まず検討する方法ではありません。
    - C: 正しい。
    - D: 誤り。コードを活かせません。

    **スキル:** [2.2.1](../domain2.md#skill-2-2-1) / **参照:** [組み込みアルゴリズム](../../../services/sagemaker.md#built-in-algorithms)、[スクリプトモード](../../../services/sagemaker.md#script-mode)

### 問7 {#q7}

学習の精度が 99%、検証の精度が 70% です。正しい診断と対策の組み合わせはどれですか。

- A. 過少適合です。より複雑なモデルにします
- B. 過学習です。正則化や早期停止を使います
- C. データドリフトです。新しいデータで再学習します
- D. コンセプトドリフトです。エポックを増やします

??? success "答えと解説"
    **正解: B**

    学習だけが高いのは過学習です。データの追加、正則化、ドロップアウト、早期停止、特徴量の削減で対応します。

    - A: 誤り。学習の精度が高いので過少適合ではなく、悪化します。
    - B: 正しい。
    - C: 誤り。学習の段階で検証だけが低いので、本番の分布の変化ではありません。
    - D: 誤り。エポックを増やすと過学習が悪化します。

    **スキル:** [2.2.5](../domain2.md#skill-2-2-5) / **参照:** [過学習](../../../services/ai-fundamentals.md#overfitting)

### 問8 {#q8}

学習の精度が 65%、検証の精度が 64% です。対策として適切なものはどれですか。（2つ選択）

- A. 正則化を弱める
- B. ドロップアウトの割合を上げる
- C. 特徴量を増やす
- D. L1 の正則化を強くする
- E. 早期停止を早める

??? success "答えと解説"
    **正解: A, C**

    両方の精度が低いのは過少適合です。特徴量を増やす、複雑なモデルにする、長く学習する、正則化を弱める、で対応します。

    - A: 正しい。強すぎる制約を緩められます。
    - B: 誤り。過学習の対策で、過少適合を悪化させます。
    - C: 正しい。モデルが捉える情報を増やせます。
    - D: 誤り。さらに重みが小さくなり、悪化します。
    - E: 誤り。学習の時間が減り、悪化します。

    **スキル:** [2.2.5](../domain2.md#skill-2-2-5) / **参照:** [過学習](../../../services/ai-fundamentals.md#overfitting)、[正則化](../../../services/ai-fundamentals.md#regularization)

### 問9 {#q9}

新しい商品のデータだけで追加学習すると、以前の商品の分類が大きく悪化しました。現象と対策の組み合わせはどれですか。

- A. 破滅的忘却です。新旧のデータを混ぜて学習します
- B. 勾配消失です。ReLU に変えます
- C. 過少適合です。正則化を弱めます
- D. データ漏えいです。分割をやり直します

??? success "答えと解説"
    **正解: A**

    破滅的忘却への対策は、新旧のデータを混ぜる、学習率を下げる、一部の層を固定する、などです。

    - A: 正しい。
    - B: 誤り。活性化関数の問題ではなく、追加学習の問題です。
    - C: 誤り。新しいデータでの追加学習で以前の内容を忘れているのが原因です。
    - D: 誤り。テストの情報の混入ではありません。

    **スキル:** [2.2.5](../domain2.md#skill-2-2-5) / **参照:** [過学習](../../../services/ai-fundamentals.md#overfitting)

### 問10 {#q10}

1 つの決定木が過学習しています。データを復元抽出で分け、複数の木を並列に学習して多数決をとります。この手法と主な効果はどれですか。

- A. 蒸留、推論のコストを下げる
- B. スタッキング、次元を下げる
- C. ブースティング、バイアスを下げる
- D. バギング、バリアンスを下げる

??? success "答えと解説"
    **正解: D**

    バギングは復元抽出で並列に学習し、平均や多数決をとります。過学習しているときに有効です。

    - A: 誤り。FM を調整する手法です。
    - B: 誤り。複数の出力を別のモデルに入れる手法で、次元削減ではありません。
    - C: 誤り。前のモデルの誤りを次が補う手法です。
    - D: 正しい。

    **スキル:** [2.2.6](../domain2.md#skill-2-2-6) / **参照:** [アンサンブル](../../../services/ai-fundamentals.md#ensembles)

### 問11 {#q11}

単純なモデルが過少適合しています。前のモデルの誤りを次のモデルが補う方法を使います。どれを選びますか。

- A. XGBoost
- B. Linear Learner を複数並列に学習して平均する
- C. k-means
- D. ランダムフォレスト

??? success "答えと解説"
    **正解: A**

    XGBoost はブースティングの例で、主にバイアスを下げます。

    - A: 正しい。
    - B: 誤り。平均をとるのはバギングの考え方で、前のモデルの誤りを補いません。
    - C: 誤り。教師なしのグループ分けで、アンサンブルの手法ではありません。
    - D: 誤り。バギングの例で、主にバリアンスを下げます。

    **スキル:** [2.2.6](../domain2.md#skill-2-2-6) / **参照:** [アンサンブル](../../../services/ai-fundamentals.md#ensembles)

### 問12 {#q12}

複数の種類のモデルの出力を別のモデルに入力して予測します。AutoGluon-Tabular も使う手法です。どれですか。

- A. バギング
- B. スタッキング
- C. カスケード
- D. ブースティング

??? success "答えと解説"
    **正解: B**

    スタッキングは複数の出力を別のモデルに入れて精度を上げます。

    - A: 誤り。同じ種類のモデルを復元抽出で学習する手法です。
    - B: 正しい。
    - C: 誤り。小さなモデルで処理して、難しいものだけ大きなモデルに渡す手法です。
    - D: 誤り。順に誤りを補う手法です。

    **スキル:** [2.2.6](../domain2.md#skill-2-2-6) / **参照:** [アンサンブル](../../../services/ai-fundamentals.md#ensembles)

### 問13 {#q13}

データ 10,000 件、バッチサイズ 100 で、10 エポック学習します。全体のステップ数はどれですか。

- A. 100,000
- B. 100
- C. 1,000
- D. 10,000

??? success "答えと解説"
    **正解: C**

    10,000 / 100 = 100 ステップが 1 エポックです。10 エポックで 1,000 ステップです。

    - A: 誤り。データの件数にエポックを掛けた値で、ステップ数ではありません。
    - B: 誤り。1 エポックのステップ数です。
    - C: 正しい。
    - D: 誤り。データの件数です。

    **スキル:** [2.2.7](../domain2.md#skill-2-2-7) / **参照:** [正則化と学習の設定](../../../services/ai-fundamentals.md#regularization)

### 問14 {#q14}

学習を始めるとすぐに損失が上下に大きく振れ、下がらなくなりました。データは正しいです。まず調整するハイパーパラメータとその方向はどれですか。

- A. ドロップアウトを増やす
- B. エポックを増やす
- C. バッチサイズを最大にする
- D. 学習率を下げて学習する

??? success "答えと解説"
    **正解: D**

    学習率が大きいと損失が発散します。小さすぎると収束が遅くなります。

    - A: 誤り。過学習の対策です。
    - B: 誤り。損失の発散は長く学習しても直りません。
    - C: 誤り。メモリ不足や汎化の低下の原因になり、学習率の問題は解決しません。
    - D: 正しい。

    **スキル:** [2.2.7](../domain2.md#skill-2-2-7) / **参照:** [正則化と学習の設定](../../../services/ai-fundamentals.md#regularization)

### 問15 {#q15}

GPU のメモリ不足で学習がすぐ失敗します。モデルは変えません。最初に調整する項目と方向はどれですか。

- A. 学習率を上げる
- B. チェックポイントの間隔を短くする
- C. エポックを減らす
- D. バッチサイズを小さくする

??? success "答えと解説"
    **正解: D**

    バッチサイズが大きいとメモリ不足になります。小さくしすぎると損失がぶれます。

    - A: 誤り。メモリの使用量は変わりません。
    - B: 誤り。メモリ不足の解決にはなりません。
    - C: 誤り。1 ステップのメモリの使用量は変わりません。
    - D: 正しい。

    **スキル:** [2.2.7](../domain2.md#skill-2-2-7) / **参照:** [正則化と学習の設定](../../../services/ai-fundamentals.md#regularization)
