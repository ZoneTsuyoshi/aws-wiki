# 機密データと安全策の問題集

対象の解説: [Guardrails のフィルター](../../../services/ai.md#guardrail-filters)、[多層防御](../../../services/genai-apps.md#defense-in-depth)、[Macie](../../../services/threat-detection.md#macie)

### 問1 {#q1}

S3 のデータレイクのどこに個人情報があるかを発見して報告します。データの変更はしません。どのサービスですか。

- A. Guardrails の機密情報フィルターを S3 バケットに関連付ける
- B. CloudTrail のデータイベントを有効にする
- C. Glue の Detect PII 変換で全データを書き換える
- D. Macie

??? success "答えと解説"
    **正解: D**

    Macie は S3 の機密データを検出して報告します。マスクはしません。

    - A: 誤り。FM の入出力の検査が目的で、S3 バケットに関連付ける機能ではありません。
    - B: 誤り。誰がアクセスしたかの記録で、中身の個人情報は発見しません。
    - C: 誤り。ETL の中で検出と置換を行う機能で、発見と報告だけが目的なら第一候補ではありません。
    - D: 正しい。

    **スキル:** [1.2.8](../domain1.md#skill-1-2-8) / **参照:** [Macie](../../../services/threat-detection.md#macie)

### 問2 {#q2}

Glue の ETL で氏名の列をハッシュに置き換え、結合のキーとして使います。元の値は復元しません。Detect PII の処理として適切なものはどれですか。

- A. 検出した値の両端だけを残して部分的に置換する
- B. SHA-256 のハッシュにする
- C. 検出のみで置換しない
- D. 検出した部分を固定の文字列に置換する

??? success "答えと解説"
    **正解: B**

    Detect PII は検出、文字列への置換、部分的な置換、SHA-256 のハッシュができます。同じ値は同じハッシュになるので結合に使えます。

    - A: 誤り。同じ値の識別にも保護にも不十分です。
    - B: 正しい。
    - C: 誤り。値が残るので要件に合いません。
    - D: 誤り。同じ値を同じ結果に変換できないので、結合のキーに使えません。

    **スキル:** [1.2.8](../domain1.md#skill-1-2-8) / **参照:** [サニタイズとマスキング](../../../services/secrets.md#sanitization-masking)、[データの保護](../../../services/genai-apps.md#data-protection)

### 問3 {#q3}

DataBrew で個人情報を保護します。後で権限のある担当者が元の値に戻す必要があります。適切な手順はどれですか。

- A. NULL 化
- B. ハッシュ
- C. 決定的または確率的な暗号化
- D. シャッフル

??? success "答えと解説"
    **正解: C**

    元の値に戻す必要があるなら暗号化です。結合のキーとして使うなら、決定的な暗号化かハッシュが適します。

    - A: 誤り。値が失われます。
    - B: 誤り。一方向の変換なので元に戻せません。
    - C: 正しい。
    - D: 誤り。同じ列の別の行の値と入れ替えるだけで、元に戻すためのものではありません。

    **スキル:** [1.2.8](../domain1.md#skill-1-2-8) / **参照:** [DataBrew](../../../services/data-engineering.md#databrew)、[データの保護](../../../services/genai-apps.md#data-protection)

### 問4 {#q4}

日本語の問い合わせ履歴から氏名と電話番号をマスクします。Comprehend の PII の非同期ジョブを使う案が出ました。正しい判断はどれですか。

- A. 適切でない。Guardrails の機密情報フィルターや正規表現を検討する
- B. 適切である。Comprehend の PII はすべての言語に対応している
- C. 適切でない。Comprehend には PII の機能がない
- D. 適切である。ただし東京リージョンのときだけ日本語に対応する

??? success "答えと解説"
    **正解: A**

    Comprehend の PII は英語とスペイン語のテキストが対象です。日本語には Guardrails の機密情報フィルターや Glue の正規表現などを検討します。

    - A: 正しい。
    - B: 誤り。対象は英語とスペイン語です。
    - C: 誤り。PII の機能はありますが、言語が合いません。
    - D: 誤り。リージョンで言語の対応が変わる機能ではありません。

    **スキル:** [1.2.8](../domain1.md#skill-1-2-8) / **参照:** [Comprehend](../../../services/ai-managed-services.md#comprehend)、[Guardrails のフィルター](../../../services/ai.md#guardrail-filters)

### 問5 {#q5}

FM のファインチューニングに使う問い合わせの回答例を、FM を呼ばずに有害な内容で検査します。どの方法ですか。

- A. `ApplyGuardrail` で各レコードを検査する
- B. 検査せず、学習後のモデルの出力だけを確認する
- C. 学習ジョブの `Faithfulness` の指標を見る
- D. `InvokeModel` にガードレールを付けて全件を推論する

??? success "答えと解説"
    **正解: A**

    `ApplyGuardrail` はモデルを呼ばずに内容を検査できます。学習データの検査にも使えます。

    - A: 正しい。
    - B: 誤り。有害な内容がそのまま学習されるおそれがあります。
    - C: 誤り。応答の評価の指標で、学習データの検査の手段ではありません。
    - D: 誤り。FM を呼ぶことになり、要件に合いません。

    **スキル:** [1.3.6](../domain1.md#skill-1-3-6) / **参照:** [ApplyGuardrail](../../../services/ai.md#apply-guardrail)、[データの準備](../../../services/genai-apps.md#fine-tuning-data)

### 問6 {#q6}

外部の委託先から FM の学習データを受け取ります。悪意のあるデータが混ざるポイズニングを防ぐ対応として適切なものはどれですか。（2つ選択）

- A. サンプルを人が確認し、スキーマを検証する
- B. ジョブの実行ロールに管理者の権限を付ける
- C. 学習データを増やすため、検査の前に全件を混ぜる
- D. データの出所を管理する
- E. 学習後の FM の temperature を 0 にする

??? success "答えと解説"
    **正解: A, D**

    FM は誤りも有害な内容もそのまま学習します。出所の管理と検証を組み合わせます。

    - A: 正しい。誤った組や不正な形式を見つけられます。
    - B: 誤り。データの検証にならず、最小権限にも反します。
    - C: 誤り。悪いデータが紛れ込む範囲が広がります。
    - D: 正しい。どこから来たデータかを追跡できます。
    - E: 誤り。生成のばらつきを減らすだけで、学習されたものは消えません。

    **スキル:** [1.3.6](../domain1.md#skill-1-3-6) / **参照:** [プロンプトのリスク](../../../services/ai-fundamentals.md#prompt-engineering)、[データの準備](../../../services/genai-apps.md#fine-tuning-data)

FM の学習データの代表性を確かめます。何を確認しますか。

    - B: 誤り。形式の確認で、代表性ではありません。
    - C: 誤り。データの中身に関係しません。

### 問8 {#q8}

RAG が読み込む外部の Web ページに、「以前の指示を無視せよ」という文が仕込まれていました。この攻撃への対策として適切なものはどれですか。（2つ選択）

- A. ベクトルストアを S3 Vectors に変える
- B. FM の `maxTokens` を増やす
- C. データソースを管理する
- D. 外部の内容をデータとして区切ってプロンプトに入れる
- E. 埋め込みの次元を増やす

??? success "答えと解説"
    **正解: C, D**

    文書の中に指示を埋め込むのは間接インジェクションです。データソースの管理とプロンプトの区切りで備えます。

    - A: 誤り。ストアを変えても、文書の中の指示は残ります。
    - B: 誤り。応答の長さの設定で、対策になりません。
    - C: 正しい。信頼できない文書が入る経路を減らせます。
    - D: 正しい。指示と区別しやすくなります。
    - E: 誤り。攻撃の対策になりません。

    **スキル:** [4.3.7](../domain4.md#skill-4-3-7) / **参照:** [多層防御](../../../services/genai-apps.md#defense-in-depth)、[プロンプトのリスク](../../../services/ai-fundamentals.md#prompt-engineering)

既知の攻撃プロンプトに対する防御の効果を、継続して確認します。適切な方法はどれですか。

- D. 攻撃のプロンプトをナレッジベースに登録する

??? success "答えと解説"

    - B: 誤り。遅延の指標で、防御の効果は分かりません。
    - C: 正しい。

    - C: 誤り。決定性の高い応答になっても、ツールの実行は制御できません。

### 問12 {#q12}

顧客対応の応答から PII をマスクし、ストリーミングで返します。ストリーミングの処理モードはどちらにしますか。

- A. 同期。遅延は増えるがマスク後に届く
- B. 非同期。遅延が少ないので必ずマスクが間に合う
- C. 非同期。`ANONYMIZE` は非同期でしか動かない
- D. ストリーミングではガードレールを使えないので、自前で正規表現を書く

    - A: 正しい。
    - B: 誤り。非同期ではマスク前の内容が届く可能性があります。
    - C: 誤り。既定は同期モードで、`ANONYMIZE` も動きます。

- A. コンテンツフィルターと機密情報フィルター
- B. 拒否トピックとコンテキストグラウンディング
- C. プロンプト攻撃フィルターと単語フィルター
- D. Automated Reasoning と `ANONYMIZE`

    **正解: B**

    話題の禁止は拒否トピック、参照元に基づかない応答の遮断はコンテキストグラウンディングです。

    - A: 誤り。有害な内容と PII の機能で、話題の禁止と根拠の検査はできません。
    - B: 正しい。
    - C: 誤り。攻撃の検出と語の一致で、要件を満たしません。
    - D: 誤り。規定との論理的な矛盾の検証とマスクで、要件を満たしません。
