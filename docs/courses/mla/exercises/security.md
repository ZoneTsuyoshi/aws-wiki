### 問1 {#q1}

プライベートサブネットにモデルを配置してエンドポイントを作ります。インターネットには出ません。モデルの取得に必要なものを選んでください。（2つ選択）

- A. パブリック IP をインスタンスに付ける
- B. `CreateEndpoint` の `AccessKey` に長期の認証情報を入れる
- C. S3 のゲートウェイエンドポイントを作る
- D. `InvocationThrottles` を監視する
- E. `CreateModel` の `VpcConfig` にサブネットと SG を指定する

??? success "答えと解説"
    **正解: C, E**

    VPC の設定は `CreateModel` の `VpcConfig` で指定します。S3 のゲートウェイエンドポイントでモデルを取得します。

    - A: 誤り。インターネットを経由しない要件に反します。
    - B: 誤り。そのような設定はなく、実行ロールで権限を渡します。
    - C: 正しい。モデルの取得に使います。
    - D: 誤り。設定の要件ではありません。
    - E: 正しい。

    **スキル:** [3.2.4](../domain3.md#skill-3-2-4) / **参照:** [VPC とネットワーク分離](../../../services/sagemaker.md#vpc-isolation)、[VPC エンドポイント](../../../services/networking.md#vpc-endpoints)

### 問2 {#q2}

コンテナからの外向きの通信を一切禁止します。どの設定ですか。

- A. `VpcConfig` だけを指定する
- B. `InitialSamplingPercentage` を 0 にする
- C. `EnableNetworkIsolation`
- D. SG のインバウンドをすべて拒否する

??? success "答えと解説"
    **正解: C**

    `EnableNetworkIsolation` はコンテナからの外向き通信を一切禁止します。

    - A: 誤り。VPC に置くだけで、通信の経路があれば外に出られます。
    - B: 誤り。データキャプチャの設定です。
    - C: 正しい。
    - D: 誤り。外向きの通信の設定ではありません。

    **スキル:** [3.2.4](../domain3.md#skill-3-2-4) / **参照:** [VPC とネットワーク分離](../../../services/sagemaker.md#vpc-isolation)

### 問3 {#q3}

VPC 内のエンドポイントの作成が失敗しました。最初に確認する項目の組み合わせはどれですか。

- A. データキャプチャの保存先があるか
- B. 本番バリアントの重みの合計が 1 か
- C. SG のインバウンドが全開放になっているか

    - B: 誤り。重みは配分の比率で、合計 1 は要件ではありません。
    - C: 誤り。モデルの取得は外向きの通信で、インバウンドの全開放は要りません。
    - D: 正しい。

    **スキル:** [3.2.4](../domain3.md#skill-3-2-4) / **参照:** [VPC とネットワーク分離](../../../services/sagemaker.md#vpc-isolation)

### 問5 {#q5}

Bedrock の API キーの管理を統制します。正しい組み合わせを選んでください。（2つ選択）

- A. 長期キーの生成は `iam:CreateServiceSpecificCredential` で制御する
- B. 環境変数の名前は `AWS_ACCESS_KEY_ID` である
- C. API キーは KMS のキーポリシーでしか制御できない
- D. 使用の可否は `bedrock:CallWithBearerToken` で制御する
- E. 短期キーは IAM ユーザーに紐づく長期の認証情報である

??? success "答えと解説"
    **正解: A, D**

    使用の可否は `bedrock:CallWithBearerToken`、長期キーの生成は `iam:CreateServiceSpecificCredential` で制御します。

    - A: 正しい。
    - B: 誤り。API キーの環境変数は `AWS_BEARER_TOKEN_BEDROCK` です。
    - C: 誤り。IAM のアクションで制御します。
    - D: 正しい。
    - E: 誤り。短期キーは生成元の権限を継承する最大 12 時間のキーです。
