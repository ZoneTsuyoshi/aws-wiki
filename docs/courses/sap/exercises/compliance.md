対象の解説: [S3](../../../services/s3.md)、[CloudTrail](../../../services/observability.md#cloudtrail)、[AWS Artifact](../../../services/threat-detection.md#artifact)、[責任共有モデル](../../../services/cloud-foundations.md#shared-responsibility)

### 問1 {#q1}

ある製薬会社は、臨床試験のデータを置く 1 つの S3 バケットについて、誰がいつオブジェクトを読んだのかを記録します。組織の証跡はすでに管理イベントを記録しています。他の数百のバケットは対象にせず、費用を最小にします。最も適切な設定はどれですか。

- A. 組織の証跡の管理イベントの読み取りを有効にして、`GetObject` を記録する
- B. 高度なイベントセレクターで、対象のバケットのデータイベントだけを記録する
- C. すべての S3 バケットのデータイベントを記録し、Athena のクエリで対象のバケットに絞る
- D. CloudTrail Insights を有効にして、読み取りの呼び出しの回数の異常を確認する

??? success "答えと解説"
    **正解: B**

    オブジェクトの読み取りはデータイベントで、既定では記録されず追加の料金がかかります。高度なイベントセレクターで対象を絞れば、費用を抑えられます。

    - A: 誤り。`GetObject` は管理イベントではありません。
    - B: 正しい。
    - C: 誤り。記録はできますが、全バケットの費用がかかります。
    - D: 誤り。Insights は呼び出しの異常の検出で、誰が読んだかの記録ではありません。

    **スキル:** [2.4.1](../domain2.md#skill-2-4-1) / **参照:** [イベントの種類](../../../services/observability.md#cloudtrail-events)

### 問2 {#q2}

あるカード会社は規制への対応で、次の 2 つを実現します。S3 の大量のバケットのどこに個人情報があるかを見つけること。アプリが CloudWatch Logs へ出力するログの中のカード番号を、権限のない人に見せないことです。それぞれに合うサービスや機能はどれですか。（2つ選択）

- A. Amazon Inspector の S3 スキャン
- B. Amazon Macie の機密データの検出
- C. GuardDuty の S3 保護プラン
- D. CloudWatch Logs のデータ保護ポリシー
- E. ログをすべて SSE-KMS で暗号化して、キーポリシーで読む人を限定する

??? success "答えと解説"
    **正解: B, D**

    S3 の機密データの発見は Macie です。CloudWatch Logs のデータ保護ポリシーは、取り込み時に機密データを検出してマスクします。ポリシーを設定する前に取り込んだログはマスクされません。

    - A: 誤り。Inspector は脆弱性のスキャンです。
    - B: 正しい。
    - C: 誤り。GuardDuty は脅威の検出で、機密データの発見ではありません。
    - D: 正しい。
    - E: 誤り。暗号化はログの読み手の中でのカード番号の露出を防ぎません。

    **スキル:** [2.4.1](../domain2.md#skill-2-4-1) / **参照:** [Macie](../../../services/threat-detection.md#macie)、[データ保護ポリシー](../../../services/observability.md#logs-data-protection)

### 問3 {#q3}

ある金融機関の S3 バケットは、次の要件を満たす必要があります。HTTP でのアクセスを拒否します。書き込まれるすべてのオブジェクトを、指定のカスタマー管理キーの SSE-KMS で暗号化します。暗号化の指定を忘れた既存のアプリも止めません。最も適切な設定はどれですか。

- A. 既定の暗号化を指定のキーにして、バケットポリシーで `aws:SecureTransport` と他のキーの指定を拒否する
- B. アプリのコードで HTTPS と KMS キーの指定を必須にして、社内のレビューで確認する
- C. Config のルールで非準拠のオブジェクトを検出して、修復の Runbook で再暗号化する。HTTP の利用は VPC フローログで確認する
- D. バケットの既定の暗号化だけを指定のキーに設定する。HTTP のアクセスは ACL で拒否する

??? success "答えと解説"
    **正解: A**

    既定の暗号化は、指定を忘れたアプリのオブジェクトも暗号化します。バケットポリシーで、`aws:SecureTransport` が `false` の要求と、指定と異なるキーでの書き込みを拒否します。

    - A: 正しい。
    - B: 誤り。AWS の統制になりません。
    - C: 誤り。事後の検出で、HTTP のアクセスも止まりません。
    - D: 誤り。ACL で HTTP を拒否することはできません。

    **スキル:** [2.4.1](../domain2.md#skill-2-4-1) / **参照:** [バケットのデフォルト暗号化とポリシーによる強制](../../../services/s3.md#enforcing-encryption)

### 問4 {#q4}

ある証券会社は、取引の記録を 7 年間、WORM で保存する規制を受けます。規制では、ルートユーザーを含め誰も期限前に削除や上書きができないことが求められます。本番の適用の前に、検証用のバケットで保持期間の設定を試します。誤った設定でも検証のデータは消せるようにします。最も適切な組み合わせはどれですか。

- A. 本番も検証もコンプライアンスモードにして、検証の期間だけを短くする
- B. 本番も検証もガバナンスモードにして、`s3:BypassGovernanceRetention` を特定の管理者だけに許す
- C. 本番はコンプライアンスモード、検証はガバナンスモードにする
- D. 本番はリーガルホールド、検証はガバナンスモードにして、本番の解除権限を監査部門に限定する

??? success "答えと解説"
    **正解: C**

    コンプライアンスモードはルートユーザーを含め誰も削除できず、期間も短縮できません。ガバナンスモードは特別な権限で解除できるので、検証に向きます。

    - A: 誤り。検証でも期間が過ぎるまで消せません。
    - B: 誤り。本番で解除できる人が残るので、規制を満たしません。
    - C: 正しい。
    - D: 誤り。リーガルホールドは期限のない保護で、権限があれば解除できます。

    **スキル:** [2.4.1](../domain2.md#skill-2-4-1) / **参照:** [Object Lock](../../../services/s3.md#object-lock)

### 問5 {#q5}

ある国の公的機関は、住民のデータを自国の外に置けません。その国に AWS リージョンはなく、自社のデータセンターにはスペースがあります。AWS と同じ API でアプリを動かし、データベースのデータもローカルに置きます。AWS との接続は確保できます。最も適切な選択はどれですか。

- A. 近隣の国のリージョンを使い、すべてのデータをカスタマー管理キーで暗号化する
- B. その国の外のリージョンの Local Zone を使い、データの場所を地理的制限で限定する
- C. データセンターに Outposts を導入する
- D. CloudFront の地理的制限で、その国の中の利用者だけへ配信する

??? success "答えと解説"
    **正解: C**

    Outposts は自社の施設に AWS の機器を置き、AWS と同じ API でデータをローカルに処理します。リージョンのない国の要件に合います。

    - A: 誤り。暗号化しても、データは国外にあります。
    - B: 誤り。Local Zones は AWS が運用する拠点で、その国にあるとは限りません。問題の条件に合いません。
    - C: 正しい。
    - D: 誤り。配信先の制限で、データの保管場所は変わりません。

    **スキル:** [2.4.2](../domain2.md#skill-2-4-2) / **参照:** [Outposts](../../../services/cloud-foundations.md#outposts)、[リージョン](../../../services/cloud-foundations.md#regions)

### 問6 {#q6}

ある規制業種の会社は、AWS のサービスの暗号化を使いたいものの、規制で「鍵は AWS の外の自社の鍵管理システムに保管し、そこで鍵を使う」ことが求められます。自社の HSM はすでに運用しており、遅延と可用性の責任を自社で負うことも合意しています。最も適切な方法はどれですか。

- A. 自社の HSM で作った鍵素材を KMS へインポートして使う
- B. CloudHSM のクラスターを作り、KMS の CloudHSM キーストアを使う
- C. KMS の既定のキーを使い、キーポリシーで AWS のサービスからの利用を限定する
- D. KMS の外部キーストアを作り、プロキシ経由で自社の HSM を使う

??? success "答えと解説"
    **正解: D**

    - A: 誤り。インポートした鍵素材は KMS の中に入ります。

### 問7 {#q7}

ある会社の情報システム部は「AWS は PCI DSS に準拠しているので、AWS 上の決済システムも自動的に準拠する」と説明しました。監査人はこの説明に同意しませんでした。正しい理解はどれですか。

- A. 正しい。AWS の準拠の報告書があれば、AWS 上のワークロードは自動的に準拠する
- B. 誤り。AWS は基盤の準拠を担い、設定とデータの準拠は利用者が示す
- C. 正しい。ただし、Well-Architected Tool でレビューを実施した場合に限る
- D. 誤り。PCI DSS の対象のサービスは存在せず、AWS 上ではカード情報を一切扱えない

??? success "答えと解説"

    責任共有モデルです。Artifact の報告書は AWS の基盤の準拠を示します。自社のワークロードの設定とデータの準拠は、自社で示します。

    - B: 正しい。
    - C: 誤り。Well-Architected のレビューは準拠の証明になりません。
    - D: 誤り。AWS の PCI DSS の報告書は Artifact から入手でき、対象のサービスで適切に構成すれば扱えます。

ある証券会社は CloudTrail の組織の証跡を Log Archive アカウントの S3 に保存しています。監査人は 2 つを求めています。後から、ログが改ざんされていないことを暗号学的に証明できること。そして、保管中のログが保持期間の間に削除されないことです。必要な設定はどれですか。（2つ選択）

- A. CloudTrail のログファイルの整合性の検証を有効にする
- B. CloudWatch Logs へ同時に送信して、ログのメトリクスフィルターで削除を監視する

### 問11 {#q11}

### 問13 {#q13}

ある多国籍企業は Control Tower のランディングゾーンを運用しています。EU の子会社の OU だけに、特定の EU のリージョン以外での操作を禁止します。他の OU は世界中のリージョンを使い続けます。最も適切なコントロールはどれですか。

- C. EU の地理的プロファイルを使い、SCP でプロファイルの送信先リージョンをすべて許可する
- D. EU の地理的プロファイルを使い、SCP では呼び出し元のリージョンだけを許可する

??? success "答えと解説"
    **正解: C**

    地理的プロファイルは処理を EU の範囲に限ります。SCP でリージョンを制限しているなら、プロファイルの送信先リージョンをすべて許可しないと、ルーティング先で拒否されます。

    - A: 誤り。グローバルプロファイルは世界の商用リージョンへ送られ、規定に反します。
    - B: 誤り。EU の外で処理されます。
    - C: 正しい。
    - D: 誤り。他の送信先リージョンでの処理が拒否される恐れがあります。

    **スキル:** [2.4.4](../domain2.md#skill-2-4-4) / **参照:** [モデル ID と推論プロファイル](../../../services/ai.md#model-identifiers)、[クロスリージョン推論（公式）](https://docs.aws.amazon.com/bedrock/latest/userguide/geographic-cross-region-inference.html)
