# 全社展開の問題集

対象の解説: [パイロットから全社展開へ](../../../services/ai-fundamentals.md#scaling)、[AWS Cloud Adoption Framework for AI](../../../services/ai-fundamentals.md#caf-ai)、[Cloud Adoption Framework](../../../services/cloud-foundations.md#caf)

### 問1 {#q1}

試験ガイドが例に挙げる、反復する変革の段階の順序として正しいものはどれですか。

- A. envision、experiment、launch、scale
- B. scale、launch、experiment、envision
- C. experiment、scale、envision、launch
- D. launch、envision、scale、experiment

??? success "答えと解説"
    **正解: A**

    試験ガイドの例は envision、experiment、launch、scale です。

    - A: 正しい。
    - B: 誤り。順序が逆。
    - C: 誤り。成果を定める前に広げることになる。
    - D: 誤り。本番に出してから成果を定めることになる。

    **スキル:** [4.4.1](../domain4.md#skill-4-4-1) / **参照:** [AWS Cloud Adoption Framework for AI](../../../services/ai-fundamentals.md#caf-ai)

### 問2 {#q2}

AWS CAF の変革の 4 段階のうち、部門間の依存と関係者の懸念を明らかにする段階はどれですか。

- A. Scale
- B. Launch
- C. Align
- D. Envision

??? success "答えと解説"
    **正解: C**

    Align で、能力の不足、部門間の依存、関係者の懸念を明らかにします。

    - A: 誤り。パイロットを広げ、価値を継続的に出す段階。
    - B: 誤り。パイロットを本番まで届け、価値を示す段階。
    - C: 正しい。
    - D: 誤り。事業の成果と機会を特定し、優先順位を付ける段階。

    **スキル:** [4.4.1](../domain4.md#skill-4-4-1) / **参照:** [AWS Cloud Adoption Framework for AI](../../../services/ai-fundamentals.md#caf-ai)、[Cloud Adoption Framework](../../../services/cloud-foundations.md#caf)

### 問3 {#q3}

変革の最初の段階（Envision）で決めるべきことはどれですか。

- A. 他部門への展開の順序と、共通基盤の標準
- B. PoC で使うモデルの細かい設定の値
- C. 全社の監視の体制と、障害時の連絡先の一覧
- D. 目指す事業の成果と KPI、スポンサー

??? success "答えと解説"
    **正解: D**

    Envision では、成果を定め、候補に優先順位を付け、目標と KPI、スポンサーを決めます。

    - A: 誤り。Scale の段階で決めること。
    - B: 誤り。技術チームの作業で、最初の段階で決めることでもない。
    - C: 誤り。本番に向けた段階で決めること。
    - D: 正しい。

    **スキル:** [4.4.1](../domain4.md#skill-4-4-1) / **参照:** [AWS Cloud Adoption Framework for AI](../../../services/ai-fundamentals.md#caf-ai)

### 問4 {#q4}

変革の進め方について、最も適切な考え方はどれですか。

- A. 1 回のサイクルですべての能力を整え、以後は変更しない
- B. 小さなサイクルを反復して進め、学びを次のサイクルに活かす
- C. 大きな目標は立てず、目の前の小さな改善だけを続ける
- D. 計画の段階で 5 年先まで確定し、学びがあっても変更しない

??? success "答えと解説"
    **正解: B**

    一度で完成させず、反復して進めます。1 回のサイクルですべてをやろうとしません。

    - A: 誤り。すべてを一度にやろうとすると、組織が疲弊する。
    - B: 正しい。
    - C: 誤り。全体像と具体的な手順の両方が必要。
    - D: 誤り。進めながら学んで調整することが前提。

    **スキル:** [4.4.1](../domain4.md#skill-4-4-1) / **参照:** [AWS Cloud Adoption Framework for AI](../../../services/ai-fundamentals.md#caf-ai)

    - C: 誤り。全社展開に向けた基盤は別に必要。

### 問21 {#q21}

利用者の増加とともに、顧客向けの AI の応答が遅くなってきました。拡大の継続を判断するうえで、最も適切な対応はどれですか。

- A. 応答が遅くても全社の展開を止めずに進める
- B. 顧客向けの機能をすべて廃止する

- D. 応答の速さは測定せず、利用者の我慢に任せる

    - B: 誤り。原因を調べずに価値を失う。
    - C: 正しい。
    - D: 誤り。問題に気づけず、離脱につながる。
