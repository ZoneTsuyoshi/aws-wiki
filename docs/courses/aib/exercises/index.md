# 問題集

話題ごとの問題集です。AIB-C01 を基準にしています。すべてオリジナルの問題で、実際の試験問題ではありません。答えは問題の下を開くと確認でき、選択肢ごとの解説と解説ページへのリンクがあります。

AIB-C01 はベータ試験です。問題の難しさや形は本番と異なる場合があります。

1. まず[学習の順番](../index.md#study-path)で範囲を確認します。
2. サービスの解説を読み、問題を解きます。
3. 間違えた問題は、解説のリンク先に戻って確認します。
