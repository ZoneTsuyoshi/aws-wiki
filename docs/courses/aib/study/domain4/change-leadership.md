## 学習の順番 {#study-order}

1. [変革の進め方](../../../../services/ai-fundamentals.md#change-management): 課題と対応の表を覚えます。
2. [役割と責任](../../../../services/ai-fundamentals.md#governance-roles): スポンサー、事業の責任者、法務の役割を確認します。
3. [人による監督](../../../../services/ai-fundamentals.md#human-oversight): 人の判断を残す場面と、役割の移行を結びつけます。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 部門間の対立で止まる | スポンサーが目標を示し、予算を確保し、対立を解く |
| チャンピオンの活動が止まった | 業務時間の確保と評価への反映 |
| 事業の成果の責任者 | 事業の責任者。技術チームではない |
| 役割の変更が未定 | 未定であることと、いつ決まるかを伝える |
| 承認が進まない | 低リスクの範囲を明示する |
| 使わずに旧来のやり方を続ける | 現場を設計に参加させ、実例を見せる |
| 失敗を隠す | 学びを称賛し、経営層も失敗を共有する |
| 全社の基礎をそろえる | 役割別の研修プログラム |
| 関心を高め、アイデアを集める | ハッカソン |
| 実務で価値を確かめる | PoC プログラム |
| 深刻な相談の自動化 | 人が担当し、AI は補助する |

## 引っかかりやすい点 {#traps}

- 根拠のない「雇用への影響はない」という約束は、後で信頼を失います。
- 命令や評価による強制だけでは定着しません。
- 責任ある AI の研修は全員に必要です。内容は役割で変えます。
