## 覚える値 {#values}

| 項目 | 値 | 判断のポイント |
|---|---|---|
| 準備状況の観点 | リーダーシップ、データ、文化、技術、ガバナンス | 技術だけではない |
| 不足の 4 領域 | 人材、プロセス、技術、ガバナンス | 試験ガイドの分け方 |
| CAF の 6 つ | Business、People、Governance、Platform、Security、Operations | 前半は事業寄り、後半は技術寄り |

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 部門ごとに目標がばらばら | リーダーシップの合意 |
| 現場が AI を脅威と感じている | 文化の準備 |
| 承認者が決まっていない | ガバナンスの枠組み |
| 数人の有志が試している | 実験の段階。最初の成功事例と基本の統治 |
| 部門ごとに基盤と標準が違う | 部門での導入の段階。共通の基盤と標準、測定 |
| 予測は良いが業務で使われない | プロセスの不足。業務の再設計 |
| 予算が限られ、不足が多い | 目標に直結し、他の前提になるものから |

## 引っかかりやすい点 {#traps}

- 段階を飛ばす計画は危険です。
- 段階の名前はモデルによって異なります。例として覚えます。
- 各段階に到達の基準を決めて、達成を確認してから進みます。
