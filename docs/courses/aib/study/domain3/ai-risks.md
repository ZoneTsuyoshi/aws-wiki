# 分野3: AI のリスクと対策

本番のリスク管理、バイアス、有害な内容と知的財産、信頼性のリスクに、どの対策を指示するかを問います。

## 学習の順番 {#study-order}

1. [本番での監視](../../../../services/ai-fundamentals.md#production-monitoring)と[統治の仕組み](../../../../services/genai-apps.md#governance-controls): 監視の対象を覚えます。
2. [バイアスと公平性](../../../../services/ai-fundamentals.md#fairness)と[ドリフトの種類](../../../../services/sagemaker.md#drift): 段階ごとの例と対策、バイアスドリフトを確認します。
3. [法的なリスク](../../../../services/ai-fundamentals.md#legal-risks)と [Guardrails](../../../../services/ai.md#guardrails): 技術の対策と契約、ルールの役割を分けて考えます。
4. [ハルシネーションへの対策](../../../../services/ai-fundamentals.md#hallucinations)と [Automated Reasoning](../../../../services/genai-apps.md#automated-reasoning): 減らす手段と限界を押さえます。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 本番に出す前に決める | 監視項目、しきい値、責任者、停止と切り戻しの手順 |
| トークンが急増した | 原因を調べ、上限を設定する |
| 正解を付けた担当者に偏見がある | ラベル付けの段階。複数人でレビューする |
| 全体は高精度だが、一部の集団で悪い | 集団ごとの指標を継続して監視する |
| 差別的な回答を防ぐ | ガードレール、公開前の評価、苦情の窓口 |
| 生成物が他者の著作物に似ている | 人の確認と、法務による利用条件の確認 |
| 公開の AI に機密情報を入力している | 承認済みツールと入力のルール |
| ウェブの文章で学習する | 出所とライセンスの確認 |
| ハルシネーションをゼロにしたい | ゼロにはできない。根拠づけ、検査、人の確認で抑える |

## 引っかかりやすい点 {#traps}

- temperature を下げても、誤りはなくなりません。
- 属性の列を消しても、関連する別の項目から偏りを学ぶことがあります。
- 導入時の公平性の検査だけでは、バイアスドリフトを捉えられません。
- SageMaker Clarify と Model Monitor は新規顧客の受付を終了しています（2026 年 10 月時点）。AIB-C01 の対象一覧に名前はありません。
