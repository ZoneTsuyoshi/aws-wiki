## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 競合が導入したので同じものを求められた | 顧客への影響と自社の強みを調べる。同じものでは追いつくだけ |
| 今の業務を安く速くする | 効率化 |
| 自社製品に AI の機能を追加する | 製品の強化 |
| 販売から継続サービスへ収益の形を変える | ビジネスモデルの変革 |
| モデルは同じで差をつけたい | 独自データ、業務への組み込み、組織の能力 |
| 活用が始まったばかりの業界 | 小さな実験と、データと人材への投資 |
| AI が業界の標準になった | 買えるものは買い、差別化する部分に投資する |
| 規制が厳しくデータ基盤も弱い | ガバナンスとデータ基盤を先に。段階的に投資する |

## 引っかかりやすい点 {#traps}

- 最新のモデルへの切り替えは、他社もすぐにできるので持続する優位になりません。
- 運用の改善の積み重ねも優位になります。
- 効率化と変革の違いは、収益の形が変わるかどうかです。
- 効率化、製品の強化、ビジネスモデルの変革という水準の分け方はこの wiki の整理で、公式の分類ではありません。
