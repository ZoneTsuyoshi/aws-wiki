# 分野2: S3 のバージョニング

削除の取り消しと古いバージョンの整理を問います。

## 問われるスキル {#skills}

| スキル | 内容 |
|---|---|
| [2.3.3](../../domain2.md#skill-2-3-3) | ストレージのバージョニング |

## 学習の順番 {#study-order}

1. [バージョニング](../../../../services/s3.md#versioning)と[状態ごとの動作と削除マーカー](../../../../services/s3.md#delete-markers): 動作を確認します。
2. [レプリケーション](../../../../services/s3.md#replication)と[ライフサイクル](../../../../services/s3.md#lifecycle): 両方のバケットの条件と古いバージョンの整理を確認します。

## こう問われたらこう考える {#decisions}

| 状況 | 判断 |
|---|---|
| 誤って削除した | 削除マーカーを削除する |
| 古いバージョンの費用を減らす | `NoncurrentVersionExpiration` |
| レプリケーションを使う | 両方のバケットでバージョニングを有効にする |

## 引っかかりやすい点 {#traps}

- 一度有効にすると無効にできず、一時停止だけです。
